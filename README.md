# Python 漫游指南 · PyJourney

一本面向已有编程基础读者的中文 Python 3.15 教程。通过分步图解和浏览器练习，学习常用语法和推荐写法。

[查看书稿](./src/content/docs) · [反馈问题](https://github.com/bosens-China/pyjourney/issues)

## 本地运行

需要 Node.js 22.23.4 或更高版本，以及 pnpm。

```sh
git clone https://github.com/bosens-China/pyjourney.git
cd pyjourney
pnpm install
pnpm dev
```

用 `pnpm check` 检查类型，用 `pnpm build` 构建站点。
