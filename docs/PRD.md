# Python 漫游指南

## 教材范围

《Python 漫游指南》是一本以 Python 3.15 为基础的交互式语言精粹，面向零基础和有一定经验的读者。全书按日常使用的语言概念编排，先讲清语法和代码行为，再用短例子验证。编写时对照官方文档核对事实，并运行代码示例。

## 章节与小节

- 点击侧栏中的章节标题展开或折叠小节列表。点击小节打开一篇独立的 MDX 文章。
- 正文围绕本节的语言概念展开，示例可以独立阅读和运行。
- 随堂练习固定在每篇正文的最后，形式包括预测题和可执行的 Python 练习。
- 章节挑战放在本章目录的最后，并有单独的编程页面。最后一篇小节的页脚也提供挑战入口。
- 小节和章节挑战使用同一套站点顶栏。挑战页采用宽布局，题目和代码编辑器在桌面并排，在窄屏上下排列。
- 挑战提供题目、样例和起始代码。读者可以运行样例，或一次检查多组数据并比较输出。

## 图解与交互

- 图解和动画帮助读者观察正文里的关键过程。按知识点选用可运行代码、静态图片、SVG 或由代码绘制的图形。
- 分步演示可以用代码更新画面，也可以依次展示一组图片或 SVG。适合连续观察的过程可以按设定间隔播放，并提供暂停和手动切步。

## 全书编排

全书分为三篇、十二章。第 1–5 章讲基础写法，第 6–8 章讲对象和迭代等语言行为，第 9–12 章把这些知识用在错误处理、数据读写、测试和建模中。章名、小节顺序和挑战用例以[章节数据](../src/data/chapters.ts)为准。
