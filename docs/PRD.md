# Python 漫游指南（PyJourney）

> 从零开始，探索 Python 的奇妙世界。

## 产品定位与理念

《Python 漫游指南》是一本以 Python 3.15 官方文档为基准的交互式电子书，对标 Douglas Crockford 经典名著《JavaScript 语言精粹》。

读者会编程，但 Python 从零开始。全书不全面介绍 Python 的所有语法，只讲优美的部分和当前的最佳实践：从最基础的语法开始，由浅入深，写今天大家实际怎么写。不考虑兼容旧版本，不讲版本迁移，不并列展示被替换的旧写法，不把标准库工具手册和性能分析器写进目录。

## 核心特色

1. **语言精粹**：沿着名字、数据、控制流、函数、模块、异常、类、迭代和包装机制这条线，只保留推荐用法。
2. **文档事实基准**：事实以 Python 3.15 官方文档为准。`frozendict`、`sentinel`、推导式内解包和惰性导入写在它们所属的章节末尾。
3. **现代交互体验**：
   - 每小节提供分步演示、预测小测或带自测的交互图解。分步图用来观察状态和执行路径，交互图解允许读者直接改变状态并观察结果。读者提交判断后，图内自测解释结果；
   - 需要独立写代码的随堂练习使用浏览器里的 `PythonExercise`；
   - 章末提供全功能交互式编程挑战页（`ChapterWorkbench`）。

## 章节体系编排（共 9 章）

- **第 1 章 · 名字与对象**（程序的样子、名字、身份、可变性）
- **第 2 章 · 数据**（数字与布尔值、文本、容器、解包、`frozendict`）
- **第 3 章 · 控制流与推导**（条件与循环、推导式与生成器表达式、模式匹配）
- **第 4 章 · 函数**（定义、参数边界、默认值与 `sentinel`、闭包）
- **第 5 章 · 模块**（导入、包、惰性导入）
- **第 6 章 · 异常**（捕获与清理、EAFP 与抛出异常）
- **第 7 章 · 类与类型**（类、特殊方法与 `property`、`dataclass`、类型标注与泛型、`Protocol`）
- **第 8 章 · 迭代器与生成器**（迭代器协议、`yield`）
- **第 9 章 · 包装机制**（装饰器、`with`、`contextlib`）

九章之前是前言（来历、取舍、读者对象、能学到什么、全书路线）。九章之后是附录「工程实践」：用 uv 管理 Python、虚拟环境和依赖，用 Ruff 格式化和检查代码，用 ty 检查类型，用 pytest 写测试，以及 VS Code 的扩展和设置。附录配有工具分层图、项目文件树、编辑器示意图，以及依赖更新和日常检查流程的分步演示。

## 阅读与练习体验

- 首页和课文使用 Rspress 默认主题。首页提供阅读入口、前言入口、四项特色、一段 Python 示例和由章节数据生成的全书目录。顶部导航提供前言、阅读入口、章末挑战下拉菜单、工程实践和 GitHub 仓库链接。课文页底有编辑链接和最后更新时间。
- 课文底部的「上一节」和「下一节」按全书的小节顺序跳转，前言在第一节之前，附录在最后一节之后。章节挑战从侧栏单独进入。手机可以分别打开章节导航和本页目录。
- 章节挑战和课文一样使用 MDX，沿用同一阅读布局。正文先展示题目，再嵌入编辑器。需要对照的输入和规则用短表说明，容易忘记的概念链接到对应课文。读者可从本页目录跳到编辑器、运行样例并检查全部用例。页底的「上一节」回到本章最后一节，「下一节」进入下一章第一节。
- 随堂练习和章节挑战的编辑器里是留有 `TODO` 的骨架。检查时既比对输出，也对代码的语法树检查题目要求的写法，逐条显示是否满足；参考答案折叠在编辑器下方，可以放进编辑器对照。
- 切片图解支持调整起点、终点和步长，立即显示取值顺序和结果。图内自测先让读者选择边界，再用新字符串检查对负数结束位置的理解。解包和参数绑定的图解让读者选择每个值的去向，再核对分配。
- 闭包图解允许用新实参调用两个闭包，观察各自读取的外层变量。迭代器图解把逐项取值、耗尽和创建新迭代器放在同一处，并用新数据检查多次求和的结果。
- 循环、模式匹配、异常和 `with` 的流程图按实际执行路线高亮连线。读者可在图内预测下一步，看到判断结果。`contextlib` 的时序图可以切换正常离开和异常离开，观察生成器恢复和清理，并检验异常发生后哪些语句会执行。
- 浅拷贝、模块导入和数据类默认值用关系图展示对象与名字的对应。生成器图解让读者逐次调用 `next()`，查看交出的值、暂停位置和耗尽状态。
- 推导式图解展示外层循环第一轮如何筛选和追加元素。星号展开另有分步演示。结构子类型用图对照协议要求和类提供的方法签名。
- 相对导入的分步图在同一棵文件树上标出当前模块、经过的包和目标文件。叠加装饰器的分步图展示表达式求值、应用装饰器和调用包装函数的顺序。
- 附录使用平台标签页展示安装命令，用步骤组件串起项目初始化、依赖安装和首次运行。
- 图解、小测和工作台跟随站点的浅色和深色主题。
