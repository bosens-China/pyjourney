## 题目

`command` 是一个序列。按它的形状决定输出。

| 指令形状 | 输出 |
| --- | --- |
| `["go", 方向]`，正好两项 | `前往 ` 加上方向 |
| `["stay"]`，正好一项 | `停留` |
| 其他形状 | `未知` |

### 题目要求

1. 使用 `match` / `case`，不要写成一串 `isinstance` 判断。
2. 方向绑定到 `direction`。
3. 输出必须与样例一致。
