## 题目

`commands` 按到达顺序记录了一批指令。逐条检查指令的内容，每条指令输出一行。

| 指令 | 输出 |
| --- | --- |
| 正好两项的 `["go", 方向]`，方向是 `north`、`south`、`east` 或 `west` | `前往 ` 加上方向 |
| `["stay"]`，正好一项 | `停留` |
| 其他指令，包括方向无效的移动指令 | `未知` |

### 题目要求

1. 用 `for` 按原来的顺序遍历 `commands`。
2. 在 `match` 中用序列模式提取方向，绑定到 `direction`。
3. 用 `case` 中的守卫检查方向是否有效。
