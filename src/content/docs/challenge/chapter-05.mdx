## 题目

`scores` 已经给定。标准库模块 `statistics` 里的 `mean` 返回平均数，`median` 返回中位数。导入这两个函数，打印这组分数的平均数和中位数。

### 题目要求

1. 用 `from statistics import ...` 写出要导入的两个名字，不使用星号导入。
2. 不要手写求和或排序。
3. 打印 `平均 x 中位 y`，两个数都保留一位小数。
