## 题目

写一个可以复用的分数报告模块。用标准库 `statistics` 中的 `mean` 计算平均数，用 `median` 计算中位数。直接运行脚本时打印报告。其他代码导入这个模块时，可以自行调用报告函数。

### 题目要求

1. 用 `from statistics import ...` 明确导入 `mean` 和 `median`。
2. 定义 `print_report(scores)`，用这两个函数算出结果，再打印 `平均 x 中位 y`，两个数都保留一位小数。
3. 把 `print_report(scores)` 的调用写在 `if __name__ == "__main__"` 下。

用例会提供 `scores`，并用不同的 `__name__` 模拟直接运行和导入。导入时应当保持安静。
