## 题目

`numbers` 已经给定。写一个生成器，只产出大于 0 的数，并把结果打印成一行。

### 题目要求

1. 使用 `yield`，不要先建成一个结果列表。
2. 保留原有顺序。
3. 用一个空格连接。没有正数时打印空行。
