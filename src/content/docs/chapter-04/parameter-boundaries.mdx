调用函数时，通常可以按位置传入实参，也可以用 `name=value` 指定形参。普通位置实参写在关键字实参之前。关键字实参按名字匹配形参，先后顺序不影响匹配结果。每个形参只能接收一个值。

函数定义可以用 `/` 和 `*` 限定传参方式。下面的定义把形参分成三组。

```python
def f(pos1, pos2, /, pos_or_kwd, *, kwd1, kwd2):
    ...
```

- `/` 之前是仅限位置形参，调用时按定义的顺序传值。
- `/` 和 `*` 之间是位置或关键字形参。定义里两个标记都没有时，形参都属于这一类。
- `*` 之后是仅限关键字形参，传值时必须写出形参名。

当调用者只需知道实参的顺序时，可以把形参设为仅限位置。公开函数以后改动这些形参的名字，调用代码也能照常运行。形参名能帮助读者理解传入的值时，可以把它设为仅限关键字。

```python run
def combined_example(pos_only, /, standard, *, kwd_only):
    print(pos_only, standard, kwd_only)

combined_example(1, 2, kwd_only=3)
combined_example(1, standard=2, kwd_only=3)
```

两次调用都把 `1` 按位置传给 `pos_only`，用 `kwd_only=3` 传入第三个值。中间的 `standard` 支持两种传法。布尔开关尤其适合设为仅限关键字。看到 `send(to, subject=subject, urgent=True)`，就知道这条消息标记为紧急。

## 其余实参

`*args` 把额外的位置实参收进一个元组。后面的形参只能按关键字传值。`**kwargs` 把没有匹配到形参的关键字实参收进一个字典。没有 `**kwargs` 的函数收到这类实参会引发 `TypeError`。两者一起用时，把 `*args` 写在 `**kwargs` 前面。

```python
def concat(*args, sep="/"):
    return sep.join(args)

concat("earth", "mars", "venus")
concat("earth", "mars", "venus", sep=".")
```

调用时，`*` 会把可迭代对象拆成位置实参，如 `concat(*planets)`。`**` 会把以字符串为键的映射拆成关键字实参，如 `connect(**options)`。

把拆开的位置实参写在关键字实参前面，例如 `concat(*planets, sep=".")`，这样更容易对照函数定义。
