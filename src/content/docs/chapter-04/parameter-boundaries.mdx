参数默认可以按位置传递，也可以按关键字传递。关键字参数写成 `name=value`，必须放在位置参数后面，顺序本身无所谓，但每个关键字都要对应一个形参，同一个形参也不能赋值两次。

函数定义里的 `/` 和 `*` 是可选标记，用来规定每个形参接受哪种传法。看定义就能确定调用方式：

```python
def f(pos1, pos2, /, pos_or_kwd, *, kwd1, kwd2):
    ...
```

- `/` 之前是仅限位置形参，顺序有意义，不能写成关键字。
- `/` 和 `*` 之间是位置或关键字形参。定义里两个标记都没有时，形参都属于这一类。
- `*` 之后是仅限关键字形参，调用时必须写出名字。`*` 放在第一个仅限关键字形参之前。

形参名没有实际意义、需要固定实参顺序，或者位置形参和关键字要同时接收时，使用仅限位置。形参名能说明含义、调用方不该依赖位置时，使用仅限关键字。对公开接口，仅限位置还可以在以后修改形参名时保持调用代码不变。

```python
def combined_example(pos_only, /, standard, *, kwd_only):
    print(pos_only, standard, kwd_only)

combined_example(1, 2, kwd_only=3)
combined_example(1, standard=2, kwd_only=3)
```

`pos_only` 不能写成 `pos_only=1`，`kwd_only` 不能只按位置传 `3`。布尔开关和含义需要说明的选项尤其适合放在 `*` 后面：`send(to, subject, urgent=True)` 比 `send(to, subject, True)` 一眼就能读懂。

## 其余实参

`*args` 把多出来的位置实参收成一个元组，一般放在形参列表靠后的位置。它后面的形参只能按关键字传递。`**kwargs` 把与形参对应不上的关键字收成一个字典，遍历顺序与调用时写出的顺序一致。两个一起用时，`*args` 在 `**kwargs` 前面。

```python
def concat(*args, sep="/"):
    return sep.join(args)

concat("earth", "mars", "venus")
concat("earth", "mars", "venus", sep=".")
```

调用处如果实参已经在序列或字典里，用 `*` 和 `**` 拆开：`concat(*planets)`、`connect(**options)`。
