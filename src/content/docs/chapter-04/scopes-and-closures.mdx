先看两层函数。调用 `inner()` 时，它自己没有绑定 `label`，于是到定义它的 `outer()` 里查找。

```python run
label = "模块"

def outer():
    label = "外层"

    def inner():
        return label

    return inner()

print(outer())  # 外层
```

函数中查找名字的顺序可以用 LEGB 记住。

1. **L（Local）**：当前函数的局部名字，最先搜索。
2. **E（Enclosing）**：外层函数的名字，从紧挨着的一层向外找。
3. **G（Global）**：当前模块的全局名字。
4. **B（Built-in）**：内置名字，例如 `len`、`print` 和内置异常，最后搜索。

函数能访问哪些外层名字，取决于它定义的位置。从其他地方调用函数，也会从原来的外层作用域查找名字。

赋值、`import` 和 `def` 都会绑定名字。函数里一旦有绑定某个名字的语句，Python 默认把它视为整个函数的局部名字。读取时如果这个局部名字还没有值，就会引发 `UnboundLocalError`。

需要重新绑定模块里的名字时，用 `global`。需要重新绑定外层函数中已有的名字时，用 `nonlocal`。如果多个外层函数都有同名绑定，`nonlocal` 选最近的一个。

## 闭包

内层函数可以引用外层变量。即使外层函数已经返回，内层函数仍能访问这些变量，这样的函数叫闭包。下面每次调用 `make_counter()`，都会创建一个带有独立计数的函数。

```python run
def make_counter():
    count = 0

    def tick():
        nonlocal count
        count += 1
        return count

    return tick

a = make_counter()
b = make_counter()
print(a())  # 1
```

每次调用 `a()`，它都会通过 `nonlocal count` 更新自己的计数。`b()` 访问的是另一次 `make_counter()` 调用创建的 `count`。

闭包在调用时读取外层变量当时的值。循环里定义的多个函数如果都引用同一个循环变量，就会共享这个绑定。循环结束后只要这个变量仍保持原值，调用这些函数时就都会读到最后一轮的值。

要让每个函数保留自己那一轮的值，可以用循环变量作默认值。定义函数时 Python 就会求出默认值。这种写法也适用于 `lambda`。

```python run
labels = []
for index in range(1, 4):
    labels.append(lambda n=index: f"第 {n} 项")

print(labels[0](), labels[2]())  # 第 1 项 第 3 项
```

每一轮创建函数时，`n=index` 都会把当时的 `index` 作为形参 `n` 的默认值。
