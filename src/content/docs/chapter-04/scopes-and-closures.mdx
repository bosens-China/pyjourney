函数中查找名字的顺序可以用 LEGB 记住。

1. **L（Local）**：当前函数的局部名字，最先搜索。
2. **E（Enclosing）**：外层函数的名字，从紧挨着的一层向外找。
3. **G（Global）**：当前模块的全局名字。
4. **B（Built-in）**：内置名字，例如 `len`、`print` 和内置异常，最后搜索。

函数能访问哪些外层名字，取决于它定义的位置。从其他地方调用函数，也会从原来的外层作用域查找名字。

函数可以直接读取外层函数和模块中的变量。如果函数体里有语句给某个名字赋值，Python 默认在整个函数体里都把它视为局部名字。先读取这个局部名字，再给它赋值，会引发 `UnboundLocalError`，即使外层已经有同名变量。`import` 和 `def` 绑定的名字也遵循这条规则。

要重新绑定模块中的名字，用 `global` 声明。要重新绑定外层函数中已有的名字，用 `nonlocal` 声明。Python 从最近的外层函数开始查找，找到绑定就停下。

```python run
def scope_test():
    def do_local():
        spam = "local spam"

    def do_nonlocal():
        nonlocal spam
        spam = "nonlocal spam"

    def do_global():
        global spam
        spam = "global spam"

    spam = "test spam"
    do_local()
    print("After local assignment:", spam)
    do_nonlocal()
    print("After nonlocal assignment:", spam)
    do_global()
    print("After global assignment:", spam)

scope_test()
print("In global scope:", spam)
```

函数需要在多次调用之间记住状态时，可以用下面的闭包。第 7 章还会介绍如何把状态放进对象。

## 闭包

内层函数可以引用外层函数的变量。即使外层函数已经返回，内层函数仍能访问这些变量，这样的函数叫闭包。下面用闭包把不同的乘数留给不同的函数。

```python run
def make_multiplier(factor):
    def multiply(x):
        return x * factor
    return multiply

double = make_multiplier(2)
triple = make_multiplier(3)
print(double(5), triple(5))  # 10 15
```

每次调用 `make_multiplier` 都有自己的 `factor`。`double` 访问的是第一次调用的 `factor`，`triple` 访问的是第二次调用的 `factor`。如果内层函数需要给这个变量重新赋值，要先声明 `nonlocal`。

闭包在调用时才读取外层变量的当前值。如果循环里定义的多个函数都直接引用同一个循环变量，循环结束后再调用它们，读到的都是最后一轮的值。

要让每个函数保留自己那一轮的值，可以用循环变量作默认值。定义函数时 Python 就会求出默认值。这种写法也适用于 `lambda`。

```python
def make_squares():
    squares = []
    for x in range(5):
        def square(n=x):
            return n**2

        squares.append(square)
    return squares
```

每一轮执行 `def square` 时，`n=x` 都会把当时的 `x` 作为 `n` 的默认值。
