`def` 后面是函数名和形参列表，下一行起是必须缩进的函数体。函数执行时使用自己的局部符号表：赋值写进这张表，实参也放进这张表。实参传递的值是对象的引用。

```python
def fib(n):
    """Print a Fibonacci series less than n."""
    a, b = 0, 1
    while a < n:
        print(a, end=" ")
        a, b = b, a + b
    print()
```

函数体的第一条语句如果是字符串，它就是文档字符串，保存在 `__doc__` 里，`help()` 和编辑器都会显示它。第一行是一句简短摘要，不必重复函数名或类型；还有更多说明时，第二行留空，再写调用约定和副作用。

形参和返回值可以写类型标注：`def fib2(n: int) -> list[int]:`。标注不影响运行，但能让读者和编辑器知道该传什么、会得到什么。第 7 章再细讲类型标注。

## 返回值

`return` 带上表达式，就把该值返回给调用方。`return` 不带表达式，或者函数执行完没有遇到 `return`，返回值都是 `None`。

```python
def fib2(n: int) -> list[int]:
    """Return a list containing the Fibonacci series up to n."""
    result = []
    a, b = 0, 1
    while a < n:
        result.append(a)
        a, b = b, a + b
    return result
```

## 函数是对象

`def` 在当前符号表里把函数名绑定到函数对象。这个对象可以赋给另一个名字，也可以传给别的函数、从函数里返回。

## Lambda 表达式

`lambda` 创建匿名函数，函数体只能是一个表达式。语义上它是常规函数定义的语法糖，也可以引用外层作用域里的变量。它适合当场需要一个很小的函数对象：作为 `list.sort()` 的 `key`，或者从外层函数返回。

```python
pairs = [(1, "one"), (2, "two"), (3, "three"), (4, "four")]
pairs.sort(key=lambda pair: pair[1])
```

```python
def make_incrementor(n):
    return lambda x: x + n
```
