用 `def` 写出函数名和形参列表，再把函数体缩进一层。每次调用都有自己的局部名字。开始执行函数体之前，Python 会把形参绑定到实参所指向的对象。

```python
def fib(n):
    """Print a Fibonacci series less than n."""
    a, b = 0, 1
    while a < n:
        print(a, end=" ")
        a, b = b, a + b
    print()
```

用普通字符串字面值作函数体的第一条语句，Python 会把它保存为文档字符串。可以用 `help(fib)` 或 `fib.__doc__` 查看上面这段文档。第一行简要说明函数做什么。需要补充调用约定或副作用时，空一行再写。

形参和返回值都可以写类型标注，例如 `def fib2(n: int) -> list[int]:`。这行告诉读者，`n` 应是整数，返回值应是整数列表。Python 不会根据标注自动检查实参和返回值。第 7 章会继续介绍类型标注。

## 返回值

带表达式的 `return` 会把表达式的值交给调用方。只写 `return`，或让函数执行到末尾，都会返回 `None`。

```python
def fib2(n: int) -> list[int]:
    """Return a list containing the Fibonacci series up to n."""
    result = []
    a, b = 0, 1
    while a < n:
        result.append(a)
        a, b = b, a + b
    return result
```

## 函数是对象

执行 `def` 会创建一个函数对象，并把函数名绑定到它。你可以让另一个名字指向同一个函数对象，也可以把它传给别的函数，或用 `return` 返回它。

## Lambda 表达式

`lambda` 用一个表达式创建函数，表达式的值就是返回值。临时需要一个简单的函数时，可以直接把它交给 `list.sort()` 的 `key`。它也能读取外层函数的变量，例如 `make_incrementor` 返回的函数会用到 `n`。

```python
pairs = [(1, "one"), (2, "two"), (3, "three"), (4, "four")]
pairs.sort(key=lambda pair: pair[1])
```

```python
def make_incrementor(n):
    return lambda x: x + n
```
