如果默认值是列表或字典，省略该实参的调用都会共用它。一次调用留下的修改，下次调用还能看到。要让每次省略实参时都得到一个新的空容器，可以把默认值设为 `None`，再在函数体里创建容器。

```python
def append_to(item, target=None):
    if target is None:
        target = []
    target.append(item)
    return target
```

数字、字符串和 `None` 都适合用作默认值。

## 没有传入，还是传入了 None

有时 `None` 本身就是一个有效的值。此时可以用内置的 `sentinel` 创建一个专门的标记，表示调用方省略了实参。

```python
MISSING = sentinel("MISSING")

def get_setting(key, default=MISSING):
    if default is MISSING:
        print(f"必须提供 {key}")
    else:
        print(f"{key}={default}")
```

| 调用 | 函数收到的 `default` | 打印 |
| --- | --- | --- |
| `get_setting("theme")` | `MISSING` | `必须提供 theme` |
| `get_setting("theme", None)` | `None` | `theme=None` |
| `get_setting("theme", "dark")` | `"dark"` | `theme=dark` |

`sentinel(name)` 的 `name` 只能按位置传入，默认也用作对象的显示名称。因此，上面的哨兵显示为 `MISSING`。通常把哨兵定义在模块顶层，让变量名和传给 `sentinel` 的名字一致。

即使两次都写 `sentinel("MISSING")`，得到的也是两个不同的对象。为同一种用途创建一次哨兵，之后用 `default is MISSING` 判断调用方是否省略了实参。

`lookup` 在 `table` 里查找 `key`。找不到时，如果调用方传了 `default`，就返回传入的值，包括 `None`。如果省略了 `default`，就返回 `缺少 键名`。
