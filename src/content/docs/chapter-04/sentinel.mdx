所以默认值如果是列表或字典这样的可变对象，所有调用都会共用它，一次调用里的修改会留到下一次。需要「没传就用一个新的空容器」时，默认值写 `None`，在函数体里再创建：

```python
def append_to(item, target=None):
    if target is None:
        target = []
    target.append(item)
    return target
```

默认值适合用数字、字符串、`None`、元组这样的不可变对象。

## 没有传入，还是传入了 None

有时 `None` 本身就是合法实参，它不能再兼任「调用方没有传这个参数」的标记。这时用内置的 `sentinel` 制作一个专用对象：

```python
MISSING = sentinel("MISSING")

def get_setting(key, default=MISSING):
    if default is MISSING:
        print(f"必须提供 {key}")
    else:
        print(f"{key}={default}")
```

| 调用 | 函数收到的 `default` | 打印 |
| --- | --- | --- |
| `get_setting("theme")` | `MISSING` | `必须提供 theme` |
| `get_setting("theme", None)` | `None` | `theme=None` |
| `get_setting("theme", "dark")` | `"dark"` | `theme=dark` |

`sentinel(name)` 的 `name` 只能按位置传，表示形式就是这个名字：上面的对象显示为 `MISSING`。按惯例，变量名和哨兵名一致，并且放在模块顶层。每次调用 `sentinel()` 都返回一个新的唯一对象，所以只创建一次，之后用 `is` 和它比较。哨兵的布尔值为真，不能用 `if not default` 判断「没有传入」。

`lookup` 在 `table` 里查 `key`。找不到时，调用方传了 `default` 就返回它，即使传的是 `None`；没有传就返回 `缺少 键名`。
