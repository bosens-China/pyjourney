包可以把相关模块组织在一起。`sound.effects.echo` 从左到右依次是包 `sound`、子包 `effects` 和模块 `echo`。

文件系统中的常规包通常是一个包含 `__init__.py` 的目录。可以把初始化代码写进这个文件，也可以让它保持为空。

先创建 `sound/` 和里面的 `effects/`，各放一个空的 `__init__.py`。然后在 `effects/` 里创建两个模块。

```python title="sound/effects/echo.py"
def repeat(text):
    return f"{text} {text}"
```

```python title="sound/effects/surround.py"
from sound.effects import echo

print(echo.repeat("hello"))
```

这是绝对导入，从顶层包 `sound` 开始写。导入后，名字 `echo` 指向子模块，调用时可以看出函数来自哪里。如果只需要函数，也可以写 `from sound.effects.echo import repeat`。

## 相对导入

在 `surround.py` 里也可以写 `from . import echo`。相对导入从当前模块所属的包开始找。下面用一棵扩充后的文件树看 `.` 和 `..` 分别指向哪里。

在包含 `sound/` 的目录运行下面的命令，就会打印 `hello hello`。无论 `surround.py` 用哪种导入，这条命令都能运行它。

```bash
python -m sound.effects.surround
```

`-m` 让 Python 按模块名找到 `surround.py`，并把它当作入口执行。此时 `__name__` 是 `"__main__"`，Python 仍然知道这个文件属于 `sound.effects`，所以能够解析相对导入。按文件路径运行 `python sound/effects/surround.py` 时，Python 缺少这份包信息。
