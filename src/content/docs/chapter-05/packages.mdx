包可以把相关模块组织在一起。例如，`A.B` 指包 `A` 里的子模块 `B`。从文件系统导入时，Python 按 `sys.path` 查找顶层包，再到父包的 `__path__` 所列位置查找子模块。

文件系统中的常规包通常是一个包含 `__init__.py` 的目录。可以把初始化代码写进这个文件，也可以让它保持为空。

```text
sound/                    ← .. 上级包
├── __init__.py
├── formats.py
├── effects/              ← . 当前包
│   ├── __init__.py
│   ├── echo.py
│   └── surround.py       ← 导入从这里出发
└── filters/
    ├── __init__.py
    ├── equalizer.py
    └── vocoder.py
```

下面三种导入写法都能调用 `echofilter`，各自绑定的名字不同。

```python
import sound.effects.echo
sound.effects.echo.echofilter(input, output, delay=0.7, atten=4)

from sound.effects import echo
echo.echofilter(input, output, delay=0.7, atten=4)

from sound.effects.echo import echofilter
echofilter(input, output, delay=0.7, atten=4)
```

`from package import item` 可以导入子模块或子包，也可以导入包里定义的函数、类或变量。`import a.b.c` 中，点号分隔的每一项都必须是包或模块。第二种写法保留了函数所属的子模块名，第三种可以直接写函数名。

## 相对导入

包内模块也可以用绝对导入。`sound.filters.vocoder` 需要 `echo` 时，可以写 `from sound.effects import echo`。相对导入从当前模块所属的包出发。以图中的 `surround.py` 为例，一个点指向 `effects`，两个点指向 `sound`。

```python
from . import echo
from .. import formats
from ..filters import equalizer
```

要运行使用相对导入的 `surround.py`，先进入 `sound/` 的上一级目录，再用完整模块名启动它。

```bash
python -m sound.effects.surround
```

`-m` 让 Python 按模块名找到 `surround.py`，并把它当作入口执行。此时 `__name__` 是 `"__main__"`，Python 仍然知道这个文件属于 `sound.effects`，所以能够解析相对导入。按文件路径运行 `python sound/effects/surround.py` 时，Python 缺少这份包信息。
