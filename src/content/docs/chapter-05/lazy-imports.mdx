`lazy` 是软关键字。在下面两种导入语句中，它让 Python 推迟加载模块。

```python
lazy import json
lazy from json import loads
```

执行 `lazy import json` 时，Python 先让 `json` 指向一个代理。代理暂时代替模块。第一次使用这个名字时，Python 才加载模块，并让 `json` 指向它。

`lazy from json import loads, dumps` 会给两个名字各绑定一个代理。第一次使用任意一个名字，Python 都会加载整个模块，并让用到的名字指向模块里对应的对象。另一个名字仍然指向代理，等到用到它时才更新绑定。

```python run
lazy import statistics
import sys

print("statistics" in sys.modules)  # False

def average(values):
    return statistics.mean(values)

print(average([1, 2, 3]))           # 2
print("statistics" in sys.modules)  # True
```

Python 把已加载的模块保存在 `sys.modules` 里。这个示例开始时，`statistics` 还没有加载。定义 `average` 时还没有执行函数体。调用 `average([1, 2, 3])` 时，函数体第一次读取 `statistics`，Python 才加载模块。如果模块不存在，错误也在这时出现。回溯会显示读取名字的位置和原来的导入语句。

日常使用普通导入。命令行工具的子命令各用一部分依赖时，可以用惰性导入。把导入语句留在文件开头，等相应的子命令用到依赖时再加载。

把惰性导入写在模块顶层。写进函数、类体或 `try` 语句会引发 `SyntaxError`。星号导入也不支持 `lazy`。

## 随堂练习

这个小工具的两个子命令各用一个模块。把文件开头的两条导入语句改成惰性导入，让模块等到首次使用时再加载。

<PythonExercise
  label="把导入改成惰性导入"
  starterCode={`# TODO：把下面两条导入改成惰性导入
  import json
  from statistics import mean

  def run(command, data):
      if command == "json":
          print(json.dumps(data))
      else:
          print(mean(data))

  run("json", [1, 2, 3])
  run("mean", [1, 2, 3])
`}
  solution={`lazy import json
  lazy from statistics import mean

  def run(command, data):
      if command == "json":
          print(json.dumps(data))
      else:
          print(mean(data))

  run("json", [1, 2, 3])
  run("mean", [1, 2, 3])
`}

  2`}
