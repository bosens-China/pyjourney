函数参数可以有默认值。调用者可以省略这个参数，也可以给它传入一个值。函数会使用实际传入的值，省略时使用默认值。

## 为参数指定默认值

在定义的参数列表中写 `step=1`，就把 `1` 设为 `step` 的默认值。下面的函数给传入的数增加一步，调用者可以选择步长。

```python
def increment(value, step=1):
    return value + step


print(increment(10))          # 11
print(increment(10, 5))       # 15
print(increment(10, step=2))  # 12
```

`increment(10)` 只给 `value` 传值，因此 `step` 取得默认值 `1`。当调用写成 `increment(10, 5)`，`step` 就取得 `5`。编写这样的参数列表时，把必须提供的参数放在有默认值的参数之前。

## 理解函数里的局部名字

调用函数时，参数名是这次调用里的局部名字。函数体里通过赋值创建的名字通常也是局部的。下面的 `total` 在函数外和函数体内分别出现。执行函数体中的赋值时，Python 在这次调用里建立一个局部名字 `total`。

```python
total = 100


def price_with_fee(price, fee=3):
    total = price + fee
    return total


print(price_with_fee(20))  # 23
print(price_with_fee(40))  # 43
print(total)               # 100
```

每次调用都有自己的局部绑定。两次调用分别用 `20` 和 `40` 计算，函数外的 `total` 仍然指向 `100`。如果想让函数的结果参与外面的计算，可以把返回值赋给一个名字。

## 随堂练习

下面的函数有一个名为 `step` 的参数，函数外也有一个同名的变量。按调用顺序预测两行输出。

```python
step = 3


def move(start, step=2):
    return start + step


print(move(10))
print(step)
```
