把可复用的函数写进 `.py` 文件，就能把这个文件当作模块，在多个脚本中使用同一份定义。例如，`import fibo` 可以导入 `fibo.py`，模块的 `__name__` 是 `"fibo"`。Python 也提供 `sys` 这样的内置模块，导入时无需对应的 `.py` 文件。

```python
import fibo

fibo.fib(1000)
fibo.fib2(100)
fibo.__name__  # 'fibo'
```

`import fibo` 让当前文件里的 `fibo` 指向模块。访问模块里的函数时，写 `fibo.fib` 或 `fibo.fib2`。也可以写 `fib = fibo.fib`，让当前文件里的 `fib` 直接指向这个函数。

Python 第一次加载模块时，先把模块放进 `sys.modules`，再执行顶层代码。再次用同一个模块名导入时，通常会复用缓存里的模块。每个模块都有自己的全局命名空间，可以用 `fibo.fib` 访问其中的名字。

通常把导入语句放在文件开头。按标准库、第三方库和本项目模块分成三组，组与组之间空一行。

```python
import json
from pathlib import Path

import requests

from myapp import settings
```

## from 与 as

`from fibo import fib, fib2` 只绑定这两个名字，它们分别指向模块里的两个函数。逐个写出需要的名字，读者就能看出它们来自哪里。`from fibo import *` 会带进一批名字，也可能覆盖同名对象的绑定。

用 `as` 可以为导入的对象指定一个本地名字。

```python
import fibo as fib
from fibo import fib as fibonacci
```

第一行让本地的 `fib` 指向模块。第二行让本地的 `fibonacci` 指向模块里的 `fib` 函数。

## 以脚本方式执行

用 `python fibo.py <arguments>` 运行脚本时，Python 会把 `__name__` 设为 `"__main__"`。把处理命令行参数的代码放进下面的分支，它就只会在直接运行时执行。

```python
if __name__ == "__main__":
    import sys
    fib(int(sys.argv[1]))
```

其他模块导入 `fibo` 时，`__name__` 是 `"fibo"`，导入会跳过这个分支。同一个文件因此既能作为命令行入口，也能让其他模块复用其中的函数。

## 模块搜索路径

在默认设置下，直接运行脚本时，Python 会在标准库目录之前搜索脚本所在的目录。给自己的模块取一个和标准库不同的名字。例如，脚本旁边的 `json.py` 可能让 `import json` 加载你写的文件。
