一条记录通常由几项固定的数据组成。例如，一个平面坐标有 `x` 和 `y` 两个值。把它们定义成带名字的字段，读代码时就能直接看出每个值表示什么。

## 定义字段并创建记录

在类定义前写上 `@dataclass`，Python 会根据带类型标注的字段生成常用方法。下面的 `Point` 会得到一个接收 `x` 和 `y` 的初始化方法，还可以直接打印出字段名和字段值。

```python
from dataclasses import dataclass


@dataclass
class Point:
    x: int
    y: int


point = Point(x=2, y=5)
print(point)    # Point(x=2, y=5)
print(point.y)  # 5
```

`x: int` 和 `y: int` 分别声明字段的名称和预期类型。创建实例时传入具体的值。之后可以用点号访问字段，例如 `point.y`。

## 给字段指定默认值

某些字段可以在创建时省略。下面的 `quantity` 默认是 `1`。如果调用时传入 `quantity=3`，这个实例就使用 `3`。

```python
from dataclasses import dataclass


@dataclass
class Item:
    name: str
    quantity: int = 1


print(Item("铅笔"))               # Item(name='铅笔', quantity=1)
print(Item("尺子", quantity=3))  # Item(name='尺子', quantity=3)
```

## 为每个实例分别创建列表

当默认值需要是一个空列表时，可以用 `field(default_factory=list)`。每次创建实例时，Python 会调用 `list()`，为这个实例生成一份新列表。

```python
from dataclasses import dataclass, field


@dataclass
class LabelGroup:
    labels: list[str] = field(default_factory=list)


first = LabelGroup()
second = LabelGroup()
first.labels.append("重点")
print(first.labels)   # ['重点']
print(second.labels)  # []
```

这里的 `list[str]` 表示列表预期存放字符串。两个实例分别拥有自己的列表，所以给 `first.labels` 添加标签后，`second.labels` 仍是空列表。
