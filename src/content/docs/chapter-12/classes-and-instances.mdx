类可以把一组数据和操作放在一起。例如，计数器需要记住当前的值，还要提供一次加一的操作。下面的 `Counter` 类描述了这两件事。

## 创建实例并设置属性

```python
class Counter:
    def __init__(self, start=0):
        self.value = start

    def increment(self):
        self.value = self.value + 1


first = Counter(2)
second = Counter()
first.increment()

print(first.value, second.value)  # 3 0
```

`class Counter:` 定义了一个名为 `Counter` 的类。调用 `Counter(2)` 会创建一个新的**实例**。创建过程中，Python 调用 `__init__()` 进行初始化，把新实例传给 `self`，把 `2` 传给 `start`。

`self.value = start` 给当前实例设置了一个名为 `value` 的**属性**。在类定义外，可以用 `first.value` 读取第一个实例中的值。

## 用方法操作当前实例

类中的 `increment()` 是一个**方法**。执行 `first.increment()` 时，Python 会把 `first` 传给方法的第一个参数 `self`。所以方法内的 `self.value` 读写的是第一个计数器。

`second` 是另一个实例，初始化时使用默认值 `0`。执行 `first.increment()` 后，两个实例的 `value` 分别是 `3` 和 `0`。

## 随堂练习

先找到调用方法时的 `self`，再判断打印的是哪个实例的属性。

```python
class Counter:
    def __init__(self, start):
        self.value = start

    def increment(self):
        self.value = self.value + 1


left = Counter(5)
right = Counter(10)
right.increment()
print(left.value)
```
