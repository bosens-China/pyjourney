生成器是写迭代器的一种方式。它看起来像普通函数，要用数据时写 `yield`。每次对生成器调用 `next()`，它从上次离开的地方继续，并记住当时的局部变量。生成器会自己提供 `__iter__` 和 `__next__`，结束时自己引发 `StopIteration`。同样的序列也可以写成上一课那种带 `__next__` 的类；生成器少写这些方法，也不必把进度存在 `self` 上。

```python
def countdown(n):
    while n > 0:
        yield n
        n -= 1

for i in countdown(3):
    print(i)
```

循环依次打印 `3`、`2`、`1`。调用 `countdown(3)` 时函数体一行都不执行，只是得到一个生成器对象；每次向它要下一项，函数体才运行到下一个 `yield`。

## 逐项传递

把几个生成器串起来，就是一条处理管道。每一级都 `yield` 当前这一项；后一级要下一项时，前一级才继续往下走。数据一项一项地穿过整条管道，中间不会为每一级各建一个列表。

```python
def stream_lines(data):
    for line in data:
        yield line.strip()

def filter_errors(lines):
    for line in lines:
        if line.startswith("ERROR"):
            yield line

def extract_code(errors):
    for err in errors:
        yield err.split(":")[1].strip()

raw = ["INFO: 启动", "ERROR: 502", "DEBUG: 探针", "ERROR: 504"]
print(list(extract_code(filter_errors(stream_lines(raw)))))
```

打印 `['502', '504']`。上面的倒计时一次 `next()` 就得到一个数。这里 `list()` 也一次向管道要一项，但筛掉一行后，管道可以继续读下一行，直到找到符合条件的结果。

## 生成器表达式

只有一个循环加一个表达式的简单生成器，写成第 3 章的生成器表达式即可：`(line.strip() for line in data)` 与上面的 `stream_lines(data)` 效果相同。逻辑需要多行语句或者要复用时，再写成生成器函数。

## 随堂练习

`fib_stream` 从 `0, 1` 开始，依次交出小于 `limit` 的斐波那契数。

<PythonExercise

  solution={`def fib_stream(limit):
      a, b = 0, 1
      while a < limit:
          yield a
          a, b = b, a + b
