在函数里用 `yield` 逐项交出数据，这个函数就成了生成器函数。调用它会得到一个生成器对象。生成器提供迭代器需要的 `__iter__` 和 `__next__`，取尽时会引发 `StopIteration`。和上一课手写的类相比，生成器把保存进度的工作交给了 Python。

```python
def countdown(n):
    while n > 0:
        yield n
        n -= 1

for i in countdown(3):
    print(i)
```

循环依次打印 `3`、`2` 和 `1`。调用 `countdown(3)` 时，Python 先创建生成器。第一次取值时，函数体运行到 `yield`，交出 `3` 并暂停。再取下一项时，生成器保留原来的局部变量，从暂停处继续执行。

## 逐项传递

把几个生成器串起来，就能让数据逐项经过多个处理步骤。后一个生成器需要取值时，前一个才继续运行，并通过 `yield` 交出下一项。各个步骤可以边读取边处理，省去保存中间结果的列表。

```python
def stream_lines(data):
    for line in data:
        yield line.strip()

def filter_errors(lines):
    for line in lines:
        if line.startswith("ERROR"):
            yield line

def extract_code(errors):
    for err in errors:
        yield err.split(":")[1].strip()

raw = ["INFO: 启动", "ERROR: 502", "DEBUG: 探针", "ERROR: 504"]
print(list(extract_code(filter_errors(stream_lines(raw)))))
```

这段代码打印 `['502', '504']`。`list()` 每次向最后一个生成器取一项，中间的 `filter_errors` 会继续读取输入，直到下一条错误消息出现，或输入已经取尽。

## 生成器表达式

简单的逐项转换可以写成[生成器表达式](../chapter-03/comprehensions.mdx)。给定同一份列表，`(line.strip() for line in data)` 和上面的 `stream_lines(data)` 会依次交出相同的值。

两种写法取得迭代器的时机不同。创建生成器表达式时，Python 就会求值最左边 `for` 子句中的可迭代对象并取得迭代器。`stream_lines(data)` 要到第一次取值才运行函数体并取得迭代器。需要多行逻辑或想复用这一段转换时，可以写成生成器函数。

实现 `fib_stream`，从 0、1 开始，逐项交出小于 `limit` 的斐波那契数。
