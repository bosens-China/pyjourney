`for` 能遍历列表、元组、字典、字符串这些容器。它在容器上调用 `iter()`，得到定义了 `__next__` 的迭代器。每次循环调用 `__next__` 取下一个元素。元素用尽时，`__next__` 引发 `StopIteration`，`for` 据此结束。内置函数 `next()` 就是去调用这个方法；自己调用到尽头时，异常会直接冒出来。

```python
it = iter("abc")
print(next(it))
print(next(it))
print(next(it))
```

第三次之后再 `next(it)`，得到的是 `StopIteration`。

## 为自己的类实现协议

`__iter__` 返回一个带 `__next__` 的对象。类自己已经定义了 `__next__` 时，`__iter__` 可以返回 `self`。下面这个类从序列末尾往前交值，取尽后把 `StopIteration` 交给 `for`。

```python
class Reverse:
    def __init__(self, data):
        self.data = data
        self.index = len(data)

    def __iter__(self):
        return self

    def __next__(self):
        if self.index == 0:
            raise StopIteration
        self.index = self.index - 1
        return self.data[self.index]
```

`for char in Reverse("spam")` 依次得到 `m`、`a`、`p`、`s`。这里 `__iter__` 返回的是同一个对象，`index` 会减到 0。再对同一个实例做一次 `for` 时，`__next__` 立刻引发 `StopIteration`，循环体不执行。容器上的 `for` 每次都会重新调用 `iter()`，所以列表可以反复遍历。

迭代器只能走一遍。需要多次遍历时，保存容器本身，每次遍历都会从它重新取得一个新迭代器。
