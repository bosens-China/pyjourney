`for` 可以遍历列表、元组、字典和字符串。它先用 `iter()` 取得迭代器，再反复调用迭代器的 `__next__` 方法取出下一项。取尽时，该方法引发 `StopIteration`，循环就结束了。

想自己逐项读取时，可以用内置函数 `next()` 调用同一个方法。

```python run
it = iter("abc")
print(next(it))
print(next(it))
print(next(it))
```

这三次调用依次取出 `a`、`b` 和 `c`。再调用一次 `next(it)` 就会引发 `StopIteration`。一旦迭代器引发过这个异常，之后每次调用它的 `__next__` 都必须继续引发这个异常。

## 为自己的类实现协议

列表这样的可迭代对象能提供迭代器，迭代器则记住取值进度。下面的 `Reverse` 本身就是迭代器，所以 `__iter__` 返回 `self`。`__next__` 从序列末尾往前取值，取尽时引发 `StopIteration`。

```python
class Reverse:
    def __init__(self, data):
        self.data = data
        self.index = len(data)

    def __iter__(self):
        return self

    def __next__(self):
        if self.index == 0:
            raise StopIteration
        self.index = self.index - 1
        return self.data[self.index]
```

`for char in Reverse("spam")` 依次得到 `m`、`a`、`p`、`s`，`index` 最终减到 0。再次用 `for` 遍历同一个实例时，`__iter__` 仍会返回它自己。`__next__` 会立刻引发 `StopIteration`，第二次循环随即结束。

每次开始遍历列表时，`for` 都会从列表取得一个新迭代器。要反复遍历这些数据，可以保留列表本身。
