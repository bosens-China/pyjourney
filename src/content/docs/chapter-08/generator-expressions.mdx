生成器表达式适合写简短的逐项计算规则。它与列表推导式的结构相似。把规则写在圆括号里，就会得到一个能陆续产出结果的生成器。

## 写一个生成器表达式

下面的规则遍历 `numbers`，只取大于 `0` 的数，把它们乘以 `2`。计算某一项结果时，生成器才执行为取得这一项所需的步骤。

```python
numbers = [-1, 2, 0, 5]
doubled = (number * 2 for number in numbers if number > 0)

print(next(doubled))  # 4
print(next(doubled))  # 10
```

第一次取值会跳过 `-1`，用 `2` 计算出 `4`。第二次会从上次的位置继续，跳过 `0`，再用 `5` 计算出 `10`。

## 交给另一个操作逐项使用

内置函数 `sum()` 可以接收可迭代对象，把其中的数相加。把生成器交给 `sum()` 后，`sum()` 会遍历它，直到生成器耗尽。

```python
numbers = [-1, 2, 0, 5]
doubled = (number * 2 for number in numbers if number > 0)

print(sum(doubled))   # 14
print(list(doubled))  # []
```

如果生成器表达式是函数调用中唯一的实参，可以省略表达式外那一对圆括号。下面把生成结果直接交给 `sum()`。

```python
numbers = [-1, 2, 0, 5]
total = sum(number * 2 for number in numbers if number > 0)
print(total)  # 14
```

如果后续还要反复遍历生成的结果，可以先把它们收集到列表。只用一遍时，生成器可以按需求值。

## 随堂练习

从 `numbers` 中取出所有大于 `0` 的数，每个数加 `1`。把生成器表达式交给 `sum()`，输出合计的整数 `8`。
