生成器是一种迭代器。自己定义生成器时，可以在函数体里用 `yield` 写出每次要交出的值。生成器会在需要下一项时继续运行。

## 调用生成器函数

定义函数的方式仍然是 `def`。函数体包含 `yield`，调用这个函数就会得到一个生成器对象。函数体中的代码在开始取值时执行。

```python
def multiples(count, factor):
    for number in range(1, count + 1):
        yield number * factor


results = multiples(3, 4)
print(next(results))  # 4
print(next(results))  # 8
print(next(results))  # 12
```

第一次调用 `next(results)` 时，循环进入第一轮。`yield` 交出 `4`，函数暂停。下一次取值时，函数从暂停处继续，走向下一轮循环。这次调用的局部状态会保留下来，例如循环进行到哪一项。

## 将剩余结果交给循环

生成器可以交给 `for`，也可以交给 `list()`。取过一项之后，后续遍历会从当前进度开始。下面的生成器先交出 `3`，随后把剩余两项放到列表里。

```python
def multiples(count, factor):
    for number in range(1, count + 1):
        yield number * factor


results = multiples(3, 3)
print(next(results))  # 3
print(list(results))  # [6, 9]
print(list(results))  # []
```

函数体运行到末尾，生成器就耗尽了。要再次从头计算，可以调用 `multiples()`，取得一个新的生成器。

## 随堂练习

跟踪每次 `yield`，判断第一次取值和剩余遍历的结果。

```python
def countdown(start):
    while start > 0:
        yield start
        start = start - 1


numbers = countdown(3)
print(next(numbers))
print(list(numbers))
```
