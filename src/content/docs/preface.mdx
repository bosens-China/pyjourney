## 为什么写这本书

Python 诞生于 1989 年的圣诞假期，1991 年 2 月第一次公开发布。三十多年过去，它被用在网站后端、数据分析、科学计算、自动化脚本等许多领域。从 3.9 开始，Python 每年发布一个新特性版本，每一版都会带来新的写法。

新写法来了，旧写法却很少消失。同一件事常常有好几种写法，而网上的教程、问答和示例代码写于不同的年代。刚学 Python 的人读到的，往往是各个年代写法的混合：不知道哪一种是今天该用的，也不知道为什么。

Douglas Crockford 在《JavaScript 语言精粹》里做过一个选择：一门语言里好的部分已经足够写出好程序，那就只讲这些部分。这本书对 Python 做同样的事。不过 Python 的麻烦不是「坏的部分太多」，而是历史上积累的写法太多。所以这里的「精粹」指的是：每个主题里今天推荐的那一种写法，以及这样写的理由。

Python 自己也提倡这一点。在解释器里输入 `import this`，会打印出一组设计格言，叫作「Python 之禅」。其中一条是：

> There should be one-- and preferably only one --obvious way to do it.
>
> 应该有一种，最好只有一种，显而易见的做法。

这本书想做的，就是在每个主题里把这「一种做法」指给你看。

## 书名

「漫游指南」不是一本手册，而是一条路线：从第一行 `print` 出发，经过名字与对象、数据、控制流、函数、模块、异常、类与类型、迭代器与生成器，最后到达装饰器和 `with` 语句。英文名 PyJourney 说的就是这段旅程。

顺便一提，Python 这个名字来自 BBC 的喜剧《Monty Python 飞行马戏团》，和蟒蛇无关。

## 这本书怎样取舍

- **一个主题，一种写法。** 只讲当前推荐的写法，不讲版本之间的迁移，也不把被取代的旧写法并列出来。要提醒一个坑时，直接教正确的形式。
- **以官方文档为准。** 全书以 Python 3.15 为基准，语法和行为以[官方中文文档](https://docs.python.org/zh-cn/3.15/)为依据。解释器的实现细节不当作可以依赖的规则来讲。
- **看得见运行过程。** 名字指向哪个对象、代码走了哪条路径，用分步图解一步步画出来。
- **边读边写。** 每课都有小测或练习，练习既检查输出，也检查写法。
- **只讲马上用得到的。** 标准库只介绍每课需要的那几个函数，不抄方法表。

## 写给谁

这本书写给已经会一门编程语言的人：变量、条件、循环、函数这些概念你不陌生，只是 Python 还要从头学起。学过一些 Python、想把写法更新到今天的人，也可以从头读一遍。

不需要事先安装任何东西。所有练习都在浏览器里运行；想在自己电脑上建项目时，再看附录。

## 读完你能做到什么

- 写出今天的 Python：f-字符串、解包、推导式、模式匹配、海象运算符 `:=`。
- 说清楚名字与对象的关系：什么时候两个名字共用同一个对象，什么时候需要一份副本。
- 用函数、模块和包组织代码，用异常处理出错的情况。
- 用类、数据类和类型标注给数据建模，让编辑器和类型检查器替你发现错误。
- 理解 `for` 背后的迭代协议，写出生成器、装饰器和上下文管理器。
- 认识 Python 3.15 的新成员：`frozendict`、`sentinel`、推导式内的解包和惰性导入。
- 用 uv、Ruff、ty 和 pytest 搭起一个真正的项目。

## 全书路线

九章由浅入深，最后是一篇附录：

1. **名字与对象**：程序的样子，名字怎样绑定到对象。
2. **数据**：数字、文本和四种容器，以及解包。
3. **控制流与推导**：条件、循环、推导式和模式匹配。
4. **函数**：参数的传法、默认值、作用域与闭包。
5. **模块**：导入、包和惰性导入。
6. **异常**：捕获、清理和抛出。
7. **类与类型**：类、数据类、类型标注和协议。
8. **迭代器与生成器**：`for` 背后的协议，以及 `yield`。
9. **包装机制**：装饰器和 `with`。

**附录：工程实践**介绍怎样在自己的电脑上搭建项目：用 uv 管理 Python 和依赖，用 Ruff、ty、pytest 检查代码，再把它们接进编辑器。

Python 3.15 新增的写法放在所属主题的末尾讲，例如 `frozendict` 跟在映射后面，`sentinel` 跟在默认参数后面。

## 怎么读

每一课都可以边读边动手：

- **分步演示**：按「下一步」或「播放」，看名字、对象和执行路径怎样一步步变化。
- **小测**：先自己预测代码的输出，再检查答案。选错时会告诉你错在哪里。
- **随堂练习**：在浏览器里直接写 Python 并运行。检查时既核对输出，也核对写法，例如是否用了推荐的语法。卡住时可以展开参考答案。
- **章末挑战**：每章最后一题综合本章内容，用多组测试检验你的实现。

页内练习运行在浏览器里的 Pyodide 上，它是 Python 3.15，书里讲到的写法都能在练习里直接运行。第一次运行时要先下载 Python 环境，需要等几秒。
