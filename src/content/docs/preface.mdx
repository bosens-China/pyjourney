## 为什么写这本书

Python 诞生于 1989 年的圣诞假期，1991 年 2 月首次公开发布。三十多年后，网站后端、数据分析、科学计算和自动化脚本中都能见到它。从 3.9 开始，Python 每年发布一个新特性版本，新的写法也逐渐积累下来。

今天学 Python，同一个问题往往能搜到几种解法。教程、问答和示例写于不同年代，刚入门时很难判断该先学哪一种。

Douglas Crockford 在《JavaScript 语言精粹》里挑出一门语言中足以写好程序的部分。本书借用这个思路，挑出今天值得先学的 Python 写法，再解释为什么选它。

在解释器里输入 `import this`，会看到一组称为「Python 之禅」的设计格言。其中一条谈的就是怎样选择写法。

> There should be one-- and preferably only one --obvious way to do it.
>
> 应该有一种，最好只有一种，显而易见的做法。

—— Tim Peters，《Python 之禅》

## 书名

「漫游指南」说的是一条学习路线。我们从第一行 `print()` 出发，一路学到装饰器和 `with` 语句。英文名 PyJourney 也取自这个想法。

Python 的名字取自 BBC 喜剧《Monty Python 飞行马戏团》。

## 这本书怎样取舍

- **优先学推荐写法。** 遇到容易踩的坑，直接演示推荐写法。迁移和旧写法留给版本文档。
- **以官方文档为准。** 全书以 Python 3.15 为基准，按[官方中文文档](https://docs.python.org/zh-cn/3.15/)说明语法和行为。涉及解释器的实现细节时，会单独说明。
- **看得见运行过程。** 分步图解会显示名字指向哪个对象、代码走了哪条路径。
- **边读边写。** 每课安排图解、小测或练习。代码练习会核对输出，有写法要求时也会检查。
- **按需介绍标准库。** 每课只挑马上用得到的函数和方法。

## 写给谁

如果你已经会一门编程语言，知道变量、条件、循环和函数怎么用，就可以从第一课开始学 Python。学过一点 Python、想更新写法的读者也可以顺着这条路线读。

打开浏览器就能运行练习。想在自己的电脑上建项目时，再看附录。

## 读完你能做到什么

- 用 f-字符串、解包、推导式、模式匹配和海象运算符 `:=` 写日常代码。
- 看懂两个名字何时共享同一个对象，以及何时需要复制对象。
- 用函数、模块和包组织代码，用异常处理出错的情况。
- 用类、数据类和类型标注给数据建模，让编辑器和类型检查器替你发现错误。
- 理解 `for` 背后的迭代协议，写出生成器、装饰器和上下文管理器。
- 认识 Python 3.15 新增的 `frozendict`、`sentinel`、推导式内解包和惰性导入。
- 用 uv 建项目，再用 Ruff、ty 和 pytest 检查代码。

## 全书路线

1. **名字与对象**从程序的样子讲起，说明名字怎样绑定到对象。
2. **数据**介绍数字、文本、容器与解包。
3. **控制流与推导**介绍条件、循环、推导式和模式匹配。
4. **函数**讲参数、默认值、作用域和闭包。
5. **模块**讲导入、包和惰性导入。
6. **异常**讲捕获异常、清理资源和抛出异常。
7. **类与类型**介绍类、数据类、类型标注和协议。
8. **迭代器与生成器**从 `for` 背后的迭代协议讲到 `yield`。
9. **包装机制**介绍装饰器和 `with` 语句。

**附录：工程实践**带你在自己的电脑上建项目，把依赖管理、代码检查和编辑器配置串起来。

Python 3.15 新增的写法放在所属主题的末尾讲，例如 `frozendict` 跟在映射后面，`sentinel` 跟在默认参数后面。

## 怎么读

- 看**分步演示**时，可以按「下一步」单步查看，或按「播放」连续查看。
- 做**小测**时，先自己判断，再检查答案。选错后可以根据提示重试。
- 做**随堂练习**时，在编辑器里写代码并运行。卡住时可以展开参考答案。
- 做**章末挑战**时，用本章学到的写法完成一道综合题，再查看每组测试的结果。
