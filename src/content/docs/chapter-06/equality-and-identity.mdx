Python 中的值由对象表示。赋值把名字绑定到对象，同一个对象可以有多个名字。下面要区分两个问题。对象表示的值是否相等，以及两个名字是否引用同一个对象。

## 比较值与比较身份

`==` 比较对象是否相等，具体的相等规则由对象的类型决定。对列表来说，两个列表长度相同且对应元素相等，两个列表就相等。`is` 检查两边是否是同一个对象。

```python
original = [1, 2]
alias = original
separate = [1, 2]

print(original == separate)  # True
print(original is separate)  # False
print(original is alias)     # True
```

执行 `alias = original` 时，两个名字绑定到同一个列表。执行 `separate = [1, 2]` 时，Python 创建一个新列表，并把 `separate` 绑定到新列表。两个列表内容相同，所以相等。两条列表表达式各自创建一个对象，所以身份不同。

## 用 is None 检查缺失值

Python 中只有一个 `None` 对象。检查某个名字是否引用它时，通常写 `is None`。这个判断可以把缺失值与有效的 `0`、空字符串或空列表区分开。

```python
value = None
print(value is None)  # True

value = 0
print(value is None)  # False
```
