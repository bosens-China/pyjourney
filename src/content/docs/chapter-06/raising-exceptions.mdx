先执行操作，再捕获预期的异常，是 Python 的一种惯用写法，简称 EAFP。例如，直接让 `int()` 尝试把文本转成整数，再处理转换失败的情况。

```python
def to_int(text):
    try:
        return int(text)
    except ValueError:
        return None

print(to_int("-3"), to_int("3.5"))  # -3 None
```

`int()` 能把 `"-3"` 转成整数，`text.isdigit()` 对它却会返回 `False`。直接用 `int()`，就能让转换和判断共用同一套规则。

## raise

函数无法完成任务时，可以用 `raise` 抛出异常。给异常实例附上一条具体说明，调用方就能知道哪里出了问题。

```python
def set_age(age):
    if age < 0:
        raise ValueError(f"年龄不能为负数：{age}")
```

在 `except` 里记录异常后，可以写一个不带参数的 `raise`。它会重新抛出当前异常，交给调用方处理。

自定义异常类直接或间接继承 `Exception`，类名通常以 `Error` 结尾。简单的异常类可以只有一个 `pass`。需要给处理器提供更多信息时，再添加相应的属性。

```python
class DatabaseError(Exception):
    pass
```

## 异常链

在 `except` 里又抛出异常时，回溯默认会显示，新异常发生在处理原异常的过程中。

把底层异常换成调用方更容易理解的异常时，可以用 `raise ... from ...` 标明直接原因。新异常的 `__cause__` 会保存原来的异常。回溯也会把原异常列为直接原因，并显示「The above exception was the direct cause of the following exception」。

```python
def func():
    raise ConnectionError

try:
    func()
except ConnectionError as exc:
    raise RuntimeError("Failed to open database") from exc  # [!code highlight]
```

想在回溯里只显示新异常时，用 `raise ... from None` 隐藏原异常。
