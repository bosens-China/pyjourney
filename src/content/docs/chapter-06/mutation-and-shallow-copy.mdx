给名字重新赋值会改变这个名字指向的对象。修改列表则会改变列表本身。如果两个名字同时指向这个列表，从两个名字读到的内容都会变化。

## 修改共享的列表

`append()` 在原列表末尾添加元素。函数参数也会绑定到传入的对象，因此在函数里对传入的列表调用 `append()`，调用处同样能看到变化。

```python
def add_value(values):
    values.append(3)


original = [1, 2]
alias = original
add_value(alias)

print(original)  # [1, 2, 3]
print(alias)     # [1, 2, 3]
```

需要保留原列表的元素时，可以在修改前调用 `list.copy()`。下面的 `copied` 指向另一个列表，添加新元素只改变这个副本。

```python
original = [1, 2]
copied = original.copy()
copied.append(3)

print(original)  # [1, 2]
print(copied)    # [1, 2, 3]
```

## 浅复制保留内部引用

`list.copy()` 创建一个新的外层列表，并把原有元素的引用放进去。这叫浅复制。原列表的元素如果也是列表，副本里的对应元素仍引用同一个内部列表。

```python
original = [[1], [2]]
copied = original.copy()
copied.append([3])
copied[0].append(4)

print(original)  # [[1, 4], [2]]
print(copied)    # [[1, 4], [2], [3]]
```

两次 `append()` 作用在不同的层。`copied.append([3])` 修改外层副本，原来的外层仍有两个元素。`copied[0].append(4)` 修改共享的第一个内层列表，于是从两个外层都能看到 `4`。

已知需要修改哪一个内层列表时，可以先单独复制它。比如写 `copied[0] = copied[0].copy()`，就会把副本的第一个元素替换为一个新列表。
