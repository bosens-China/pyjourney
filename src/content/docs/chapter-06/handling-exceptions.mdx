Python 在运行代码前会检查语法，遇到语法错误时会标出发现问题的位置。语法正确的代码在运行时也可能引发异常。例如，`10 * (1/0)` 会引发 `ZeroDivisionError`，`'2' + 2` 会引发 `TypeError`。回溯列出异常经过的调用位置，通常在末尾显示异常类型和错误信息。

## try、except、else、finally

Python 先执行 `try` 子句。遇到异常时，会跳过其中剩余的语句，按顺序查找第一个匹配的 `except`。找不到匹配的处理器，异常就继续向外传播。异常传到程序的最外层时，解释器通常会显示回溯。

`except` 匹配指定类及其派生类的实例。若派生类和基类都有各自的处理器，把派生类写在前面。几种具体异常共用一个处理器时，可以把类型写成元组，如 `except (OSError, ValueError) as err:`。

`except ValueError as err` 会把名字 `err` 绑定到捕获的异常实例。可以直接打印 `err` 来查看错误信息，也可以通过 `err.args` 查看异常的参数。

`else` 可选，写在所有 `except` 后面。`try` 子句顺利执行到末尾才会进入 `else`。用 `return`、`break` 或 `continue` 提前退出时，会直接跳过 `else`。把成功后要做的事放在 `else`，前面的 `except` 就只会处理 `try` 子句中的异常。

`finally` 可选。写了它，就会在离开整条 `try` 语句前执行，适合用来释放资源。即使发生异常，或 `try` 里已经执行了 `return`，也会先完成 `finally`。未处理的异常随后继续向外传播。

:::warning 当心提前离开 finally

在 `finally` 里用 `return`、`break` 或 `continue` 提前离开子句，会丢掉正在传播的异常。让 `finally` 专心做清理。

:::

```python
def divide(x, y):
    try:
        result = x / y
    except ZeroDivisionError:
        print("division by zero!")
    else:
        print("result is", result)
    finally:
        print("executing finally clause")
```

## 捕获具体的异常

`BaseException` 是所有异常的基类。平常需要处理的内置异常大多继承自 `Exception`。`SystemExit` 表示程序要退出，`KeyboardInterrupt` 表示用户要中断程序。这两个类都直接继承自 `BaseException`，捕获 `Exception` 时会让它们继续向外传播。

优先捕获知道如何处理的具体异常，让意外的错误继续传播。需要统一记录错误时，可以捕获 `Exception`，记录后用不带参数的 `raise` 重新抛出。把 `try` 子句限制在需要捕获异常的操作上。

```python
try:
    with open("config.txt") as f:
        port = int(f.readline())
except OSError as err:
    print("读不了配置文件：", err)
except ValueError:
    print("第一行不是整数")
```
