条件语句让程序根据判断结果选择接下来执行哪段代码。比如每天读满 20 页就显示“达标”，页数少于 20 时显示“继续阅读”。这里的条件是“页数大于等于 20”。

## 用比较表达条件

比较两个值会得到一个布尔值，即 `True` 或 `False`。数值之间可以比较大小，也可以检查是否相等。

```python
pages = 20
print(pages >= 20)  # True
print(pages < 20)   # False
print(pages == 20)  # True
```

`>=` 把等于边界的情况也算进去。`>` 表示严格大于。小于对应 `<`，小于等于对应 `<=`，不相等用 `!=`。写 `pages = 20` 是给名字赋值，写 `pages == 20` 是比较两个值。

## 用 if 执行符合条件的代码

`if` 后面写条件，行末加冒号。把这个分支的代码缩进一层。本书用四个空格表示一层缩进。条件成立时，Python 执行缩进的代码。可以给 `if` 加上 `else`，在条件不成立时执行另一个分支。

```python
pages = 18

if pages >= 20:
    print("达标")
else:
    print("继续阅读")

print("登记完成")
```

这段代码会先输出“继续阅读”，再输出“登记完成”。最后一行回到最左边，已经离开了两个分支。执行完任何一个分支，都会继续执行这一行。

## 按顺序检查多个条件

写 `elif` 可以补充另一项条件。Python 从上往下检查，到第一个成立的条件就停止检查，执行它对应的分支。若前面的条件都不成立，就执行最后的 `else`。

```python
pages = 30

if pages >= 30:
    print("达到进阶目标")
elif pages >= 20:
    print("达到日目标")
else:
    print("继续阅读")
```

对于 30 页，两个比较都成立。第一项条件已经选中分支，所以这段代码只输出“达到进阶目标”。当较宽的条件会覆盖较窄的条件时，把较窄的条件写在前面。

## 组合条件

用 `and` 表达两项条件同时成立，用 `or` 表达至少一项成立。用 `not` 可以反转一个条件。下面的例子要同时满足页数足够和已经登记两项要求。

```python
pages = 24
recorded = False

print(pages >= 20 and recorded)  # False
print(pages >= 20 or recorded)   # True
print(not recorded)              # True
```

## 随堂练习

一份记录需要满足两个条件才显示“达标”。用下面的两项数据判断。

```python
pages = 20
recorded = True
```

页数要达到 20，记录也要已经登记。选出能表达这两项要求的条件。
