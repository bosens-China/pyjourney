赋值号右边用逗号隔开的值会组成元组。把右侧的各项按顺序分给左侧的名字，叫作解包。右侧可以是任意可迭代对象。左侧没有星号时，两侧的项数必须相同，每个名字接收一项。

赋值时，Python 先算完右侧，再绑定左侧。这样，`a, b = b, a` 就能交换两个名字原来绑定的值。

```python
t = 12345, 54321, "hello!"
x, y, z = t
```

## 星号

可以用一个带 `*` 的名字接收剩余项。星号前的名字从开头取，星号后的名字从末尾取，每个名字各接收一项。Python 把剩下的项收进列表，交给星号对应的名字。没有剩余项时，会得到空列表。

<UnpackingGroups />

在元组或列表的写法里，`*` 会把可迭代对象的各项展开到新序列中。下面先用 `*` 接收剩余项，再用它展开一个列表。

```python run
head, *middle, tail = [1, 2, 3, 4]
print(middle)  # [2, 3]

x = [1, 2, 3]
print((0, *x, 4))  # (0, 1, 2, 3, 4)
```

函数调用也可以用 `*` 展开序列。下面的 `*args` 把 3 和 6 按位置传给 `range()`，就像直接写 `range(3, 6)`。

```python run
args = [3, 6]
print(list(range(*args)))  # [3, 4, 5]
```

## 字典

写新字典时，可以用 `**` 展开已有字典的键值对。同一个键出现多次时，以最后填入的值为准。只合并两个字典时，可以直接用 `|`。

```python run
defaults = {"color": "blue", "size": 10}
custom = {"size": 12}
print({**defaults, **custom, "debug": True})  # {'color': 'blue', 'size': 12, 'debug': True}
print(defaults | custom)                      # {'color': 'blue', 'size': 12}
```

在函数调用中，`**` 会把字典展开成按名字传入的值，也就是关键字实参。第 4 章会用到这个写法。
