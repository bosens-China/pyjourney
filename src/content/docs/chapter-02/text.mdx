文本的类型是 `str`。单引号和双引号都可以写字符串。文本里只有一种引号时，可以用另一种包住它。`\n` 是换行，三重引号的字符串可以跨行。

在引号前加 `r` 就得到原始字符串，里面的 `\n` 会原样保留为反斜杠和字母 n。原始字符串常用于正则表达式。如果末尾有反斜杠，它们必须成对。参见 [Python 3.15 原始字符串字面量](https://docs.python.org/zh-cn/3.15/reference/lexical_analysis.html#raw-string-literals)。

## 下标与切片

字符串是字符的序列。从左边数，第一项的下标是 `0`。从右边数，最后一项的下标是 `-1`。例如，`word = "Python"` 时，`word[0]` 得到 `P`，`word[-1]` 得到 `n`。

用 `word[start:stop]` 取一段字符。从 `start` 对应的字符开始，取到 `stop` 对应的字符之前。可以把两个端点想成字符之间的边界。从左往右取时，省略起点就从头开始，省略终点就取到末尾。

`word[start:stop:step]` 的第三项是步长，控制每次移动几个位置。省略步长时用 `1`，写成 `0` 会引发错误。正数向右取，负数向左取。步长的绝对值越大，每次跨得越远。省略两个端点时，`word[::2]` 从左端隔一个取一个，`word[::-2]` 从右端隔一个取一个。

`word[:i]` 和 `word[i:]` 分别取边界 `i` 左右两段，拼起来就是 `word`。用下标访问越界的位置时，Python 会引发 `IndexError`。切片会把越界的端点收回到有效范围。用 `len()` 可以得到字符串的长度。

字符串不可变。用 `"J" + word[1:]` 可以把新首字母和后面的字符拼成一个新字符串。

## 常用操作

下面用 `strip()` 去掉两端空白，用 `split()` 拆成字段列表。随后用 `join()` 拼回字符串。要检查开头是否匹配，用 `startswith()`，它返回布尔值。

```python run
line = "  name,age,city  "
fields = line.strip().split(",")
print(fields)                # ['name', 'age', 'city']
print(" | ".join(fields))    # name | age | city
print("age" in line)         # True
print(line.startswith("name"))  # False，开头还有空白
```

`in` 检查一段文本是否出现在字符串中。给 `split()` 传入分隔符，就按该分隔符切开。直接调用 `split()` 时，连续的空白算作一处分隔符，两端的空白会被略过。要拼接多个片段，就在分隔字符串上调用 `join()`，例如 `" | ".join(fields)`。

## f-字符串

在引号前写 `f`，就可以把名字或表达式放进花括号。运行时，Python 会算出表达式的值，再把它填进文本。要输出花括号本身，把它写成 `{{` 或 `}}`。

```python run
name = "Ada"
total = 1234.5
print(f"{name} 共消费 {total:,.2f} 元")  # Ada 共消费 1,234.50 元
print(f"{name!r:>8}")                    #    'Ada'
print(f"{total=}")                       # total=1234.5
```

冒号后面可以指定格式。`.2f` 显示两位小数，`,` 加上千位分隔符，`>8` 在至少 8 个字符的宽度里右对齐。`!r` 用 `repr()` 得到值的文本表示。在表达式后加 `=`，就会同时输出表达式和值，方便调试。
