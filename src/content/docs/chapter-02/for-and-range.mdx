`for` 循环逐个取出元素，对每个元素执行同一段代码。逐个处理元素的过程也叫遍历。例如，想把一段文字逐字输出时，可以每次取一个字符，再执行同一行输出代码。

## 逐个处理元素

`for` 后面的名字接收当前元素。`in` 后面写要遍历的对象。行末写冒号，缩进的部分是每次都要执行的代码，也叫循环体。

```python
for letter in "ABC":
    print(letter)
```

这段代码依次输出 `A`、`B` 和 `C`，每个字母占一行。每一轮开始时，`letter` 都会绑定到刚取出的字符。

## 用 range() 给出整数范围

当循环需要一组连续整数时，可以用 `range()`。例如，`range(3)` 从 0 开始，依次给出 0、1 和 2。指定两个参数时，第一个是起点，第二个是终点。起点包含在范围内，终点是停止位置。

```python
for day in range(3, 6):
    print(day)
```

输出为 3、4、5。要遍历第 1 天到第 7 天，终点应写成 8，也就是 `range(1, 8)`。

## 把每一轮的结果累加起来

在循环前给累计值一个初值，在循环里更新它。以下代码用三轮循环计算 1 加 2 加 3 的结果。

```python
total = 0
for count in range(1, 4):
    total = total + count

print(total)  # 6
```

累加从 0 开始。每轮把 `count` 加到当前的 `total` 上，再用结果更新 `total`。输出写在循环外，因此只会显示最后的总数。
