`frozendict` 是内置的不可变映射。创建之后不能再修改：按下标赋值会引发 `TypeError`。它直接继承自 `object`，不是 `dict` 的子类，所以 `isinstance(frozen, dict)` 为假。要同时接受这两种映射，可以写 `isinstance(value, (dict, frozendict))`；`collections.abc.Mapping` 还会接受其他映射。

构造方式和 `dict` 相同：可以传关键字参数、一个映射，或者一个由键值对组成的可迭代对象。它保留插入顺序，但相等比较不看顺序：键值对相同即为相等。

:::note 什么时候可以当作字典的键

`frozendict` 可以存放列表这样的不可哈希值。要把这个映射放进集合或当作字典的键，它自己的键和值就都得可哈希。

:::

```python
a = frozendict(x=1, y=2)
b = frozendict(y=2, x=1)
print(a)           # frozendict({'x': 1, 'y': 2})
print(a == b)      # True
print(hash(a) == hash(b))  # True
```

程序里不应被修改的配置表、作为默认值的映射，以及需要放进集合或当作键的映射，都适合用 `frozendict`。
