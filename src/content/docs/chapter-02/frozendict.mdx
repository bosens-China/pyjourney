`frozendict` 是内置的不可变映射，适合保存一组固定选项。和创建 `dict` 一样，可以传入关键字参数、另一个映射或一组键值对。试图给已有的 `frozendict` 按键赋值时，Python 会引发 `TypeError`。

每个键都固定指向原来的值。如果值是列表，仍可往列表里追加元素。这组标签也可以用元组保存，让标签本身也固定下来。

```python run
config = frozendict(tags=["python"])
config["tags"].append("入门")
print(config["tags"])  # ['python', '入门']
```

`frozendict` 保留键值对的插入顺序。两个 `frozendict` 包含相同的键值对就相等，它们的插入顺序可以不同。

:::note 什么时候可以当作字典的键

`frozendict` 可以存放不可哈希的值，例如列表。如果里面的键和值都可哈希，就能把整个 `frozendict` 放进集合，或用作字典的键。

:::

## 随堂练习

`prices` 按颜色和尺码记录商品价格。用 `frozendict` 创建 `red_m` 和 `red_l`，把每组商品选项当作一个键。查询时，同一组颜色和尺码可以按任意顺序写。

`frozendict` 直接继承自 `object`。要同时接受 `dict` 和 `frozendict`，可以用 `isinstance(value, (dict, frozendict))` 检查。要接受其他映射类型，可以用 `collections.abc.Mapping` 检查。参见 [Python 3.15 的 frozendict 说明](https://docs.python.org/zh-cn/3.15/builtins/stdtypes.html#frozendict)。
