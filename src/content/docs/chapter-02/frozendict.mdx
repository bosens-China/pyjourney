`frozendict` 是内置的不可变映射，适合保存一组固定选项。创建时可以像下面这样，用 `tags=` 指定键及其值。创建后，每个键都固定指向原来的值。按键赋值会引发 `TypeError`。

如果值是列表，仍可往列表里追加元素。下面用元组保存标签，让标签也固定下来。

```python run
config = frozendict(tags=("python", "入门"))
print(config["tags"])  # ('python', '入门')
```

`frozendict` 保留键值对的插入顺序。两个 `frozendict` 包含相同的键值对就相等，它们的插入顺序可以不同。

```python run
a = frozendict(x=1, y=2)
b = frozendict(y=2, x=1)
print(a)       # frozendict({'x': 1, 'y': 2})
print(b)       # frozendict({'y': 2, 'x': 1})
print(a == b)  # True
```

:::note 什么时候可以当作字典的键

`frozendict` 可以存放不可哈希的值，例如列表。如果里面的键和值都可哈希，就能把整个 `frozendict` 放进集合，或用作字典的键。

:::
