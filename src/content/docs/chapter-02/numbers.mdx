## 整数与浮点数

整数的类型是 `int`，精度没有上限，`2 ** 100` 也能精确算出来。带小数部分的数是 `float`。整数和浮点数混合运算时，整数先转换成浮点数，结果是浮点数。数字字面值里可以用下划线分组，方便阅读：`1_000_000` 就是一百万。

```python
print(2 ** 100)      # 1267650600228229401496703205376
print(4 * 3.75 - 1)  # 14.0
print(1_000_000)     # 1000000
```

## 四种除法相关的运算

- `/` 总是返回浮点数，即使能整除：`8 / 2` 是 `4.0`。
- `//` 是向下取整除法，结果朝负无穷方向舍入：`17 // 3` 是 `5`，`-7 // 2` 是 `-4`。
- `%` 是对应的余数，满足 `(x // y) * y + x % y == x`：`17 % 3` 是 `2`，`-7 % 2` 是 `1`。
- `divmod(x, y)` 一次返回 `(x // y, x % y)`。

`**` 是乘方。`int("42")` 和 `float("3.5")` 把文本转换成数字，`str(42)` 反过来。`int(3.9)` 直接丢掉小数部分得到 `3`，要向上或向下取整时用 `math.ceil` 和 `math.floor`，四舍五入用 `round`。

浮点数是二进制近似值，`0.1 + 0.2 == 0.3` 为假。比较两个浮点数是否相等时，用 `math.isclose`。

## 布尔值

比较运算得到布尔值 `True` 或 `False`，类型是 `bool`。`bool` 是 `int` 的子类，`True` 在数字场景下表现得像 `1`，但不要把它当数字用；需要整数时用 `int()` 显式转换。

任何对象都能当作条件。以下这些是假值，其余对象默认都是真值：

- `None` 和 `False`
- 数值零：`0`、`0.0`
- 空的序列和容器：`""`、`()`、`[]`、`{}`、`set()`、`range(0)`

所以检查列表是否为空，直接写 `if items:`，不必写 `if len(items) > 0:`。

## None

`None` 表示「没有值」。没有 `return` 的函数返回 `None`，字典的 `get` 找不到键时也返回 `None`。`None` 只有一个，判断时用 `is`：`if result is None:`。不要写 `== None`，也不要用 `if not result:` 代替，因为 `0` 和空字符串同样是假值。
