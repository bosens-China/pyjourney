## 整数与浮点数

整数的类型是 `int`，没有固定的精度上限。例如，Python 可以精确算出 2 的 100 次方，也就是 `2 ** 100`。`3.75` 和 `4.0` 都是 `float`。整数和浮点数相加、相减或相乘时，结果是浮点数。

直接写数字时，可以用下划线分组。例如，`1_000_000` 表示一百万。

```python run
print(2 ** 100)      # 1267650600228229401496703205376
print(4 * 3.75 - 1)  # 14.0
print(1_000_000)     # 1000000
```

## 除法、商与余数

下面以两个整数相除为例。

- `/` 返回浮点数，即使能整除。例如 `8 / 2` 得到 `4.0`。
- `//` 的结果朝负无穷方向取整。`17 // 3` 得到 `5`，`-7 // 2` 得到 `-4`。
- `%` 返回余数。`17 % 3` 得到 `2`，`-7 % 2` 得到 `1`。把 `//` 得到的商乘以除数，再加上余数，就得到原来的整数。
- `divmod(x, y)` 同时返回商和余数，即 `(x // y, x % y)`。

`int("42")` 和 `float("3.5")` 把文本转换成数字，`str(42)` 把数字转换成文本。用 `int()` 把浮点数转成整数时，会去掉小数部分。例如，`int(3.9)` 得到 `3`。

`round()` 默认舍入到最接近的整数。数值正好在两个整数中间时，就选其中的偶数。所以 `round(2.5)` 得到 `2`，`round(3.5)` 得到 `4`。参见 [Python 3.15 的 round() 说明](https://docs.python.org/zh-cn/3.15/builtins/functions.html#round)。

在常见的二进制浮点表示中，`0.1`、`0.2` 和 `0.3` 都是近似值，所以 `0.1 + 0.2 == 0.3` 为假。需要判断两个浮点数是否足够接近时，用标准库的 `math.isclose()`。参见 [Python 3.15 浮点算术教程](https://docs.python.org/zh-cn/3.15/tutorial/floatingpoint.html)。

## 布尔值

比较两个数字时，结果是布尔值 `True` 或 `False`，类型是 `bool`。

任何对象都能用作条件。下面列出了常见的假值。其他对象默认是真值。

- `None` 和 `False`
- 数值零，例如 `0` 和 `0.0`
- 空序列和空容器，例如 `""`、`()`、`[]`、`{}`、`set()` 和 `range(0)`

检查列表是否有元素时，可以直接写 `if items:`。

## None

`None` 表示「没有值」。函数执行到末尾时会返回 `None`。字典找不到键时，`get()` 默认也返回 `None`。

Python 只有一个 `None` 对象。用 `if result is None:` 可以判断 `result` 是否表示没有值。`0` 和空字符串也是假值，但它们都可以表示有效结果。
