列表、元组和字符串都是序列，可以用下标和切片。集合用来做成员检测和去重。字典用键取值。简单赋值都不复制容器：两个名称可以绑在同一个列表或字典上。

| 容器 | 怎样访问 | 可变 | 常见用途 |
| --- | --- | --- | --- |
| 列表 `list` | 下标、切片 | 是 | 保存可增删的一串数据 |
| 元组 `tuple` | 下标、切片 | 否 | 保存一组固定位置的值 |
| 集合 `set` | `in` 检查成员，无下标 | 是 | 去重、检查某项是否存在 |
| 字典 `dict` | 用键取值 | 是 | 按名字或编号查找对应的值 |

## 列表

列表用方括号写出，元素通常是同一类，通过迭代来用。列表可变，可以按下标替换元素；切片赋值还能改变长度，包括把整段换成空列表。`append` 在末尾加入一项。切片会返回一个新列表，是原列表的浅层复制。

```python
cubes = [1, 8, 27, 65]
cubes[3] = 64
cubes.append(125)
```

## 元组

元组由逗号分隔的值组成，圆括号常常可以省略，嵌套或作为更大表达式的一部分时则需要。元组不可变，一般用来放不同类型的一项项数据，用解包或下标读取。它里面仍然可以放列表这样的可变对象；不能替换的是元组自己的那些槽位。

空元组写成 `()`。只含一个元素时，这个元素后面要有逗号，否则圆括号只是分组：

```python
singleton = ("hello",)
empty = ()
```

固定的一组值用元组。还要增删或替换元素时用列表。

## 集合

集合是不含重复元素的无序容器，用花括号写出。重复的元素只会留下一个。`in` 用来做成员检测。空集合必须写 `set()`，因为 `{}` 是空字典。集合支持并、交、差和对称差：`|`、`&`、`-`、`^`。

```python
basket = {"apple", "orange", "apple"}
print("orange" in basket)  # True
```

## 字典

字典是键到值的映射。键必须可哈希：字符串和数字总可以；元组只有在它直接或间接包含的都是可哈希对象时才可以。列表不能做键。键必须唯一，再次写入会换掉旧值。

`{}` 是空字典。`d[key]` 在键不存在时引发 `KeyError`；`get` 在缺少键时返回 `None`，也可以传入默认值。`del d[key]` 删除一项。`list(d)` 按插入顺序返回全部键，`in` 检查的是键。字典保留插入顺序；比较相等只看键值对是否相同，不看顺序。

```python
tel = {"jack": 4098, "sape": 4139}
tel["guido"] = 4127
print(tel.get("irv"))  # None
```

键值对序列也可以交给 `dict()`。键是合法标识符时，可以直接写关键字参数：`dict(sape=4139, guido=4127)`。
