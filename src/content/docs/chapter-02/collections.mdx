列表、元组和字符串都是序列，可以用下标取一项，用切片取一段。集合适合去重，也方便检查某项是否存在。字典把键和值配对，查找时用键取值。和上一章的列表一样，赋值可以让两个名字指向同一个容器。

| 容器 | 怎样访问 | 可变 | 常见用途 |
| --- | --- | --- | --- |
| 列表 `list` | 下标、切片 | 是 | 保存可增删的一串数据 |
| 元组 `tuple` | 下标、切片 | 否 | 保存一组固定位置的值 |
| 集合 `set` | `in` 检查成员，无下标 | 是 | 去重、检查某项是否存在 |
| 字典 `dict` | 用键取值 | 是 | 按名字或编号查找对应的值 |

## 列表

用方括号写列表，通常把同类的数据放在一起，再逐项处理。可以按下标替换元素，也可以用 `append()` 在末尾追加一项。

```python
cubes = [1, 8, 27, 65]
cubes[3] = 64
cubes.append(125)
```

给一段普通切片赋值，可以用不同数量的元素替换这一段。换成空列表就会删除这一段。单独读取切片时，会得到一个新列表，其中的元素仍是原来的对象。

## 元组

元组用逗号分隔各个值。圆括号通常可以省略，嵌在其他表达式里时用圆括号标明范围。元组适合把不同类型的值放在固定位置，可以用解包或下标读取。元组的每个位置固定指向原来的对象，位置上如果放了列表，列表本身仍能修改。

空元组写成 `()`。单元素元组要在元素后加逗号，用逗号区分元组和普通的括号分组。

```python
singleton = ("hello",)
empty = ()
```

固定的一组值用元组。还要增删或替换元素时用列表。

## 集合

集合用大括号写出，元素没有固定顺序，相同的元素只保留一个。用 `in` 检查某项是否在集合里。空集合写成 `set()`，`{}` 表示空字典。

```python run
basket = {"apple", "orange", "apple"}
print(len(basket))         # 2
print("orange" in basket)  # True
```

## 字典

字典用键查找对应的值。键必须可哈希。可哈希对象在存在期间有稳定的哈希值，也能和其他对象比较是否相等。参见 [Python 3.15 术语表](https://docs.python.org/zh-cn/3.15/glossary.html#term-hashable)。

字符串和数字可哈希，可以当键。如果元组的每一项都可哈希，元组也可以当键。列表不可哈希。再次给同一个键赋值，会替换原来的值。

`{}` 是空字典。键不存在时，`d[key]` 会引发 `KeyError`，`d.get(key)` 则返回 `None`。也可以给 `get()` 传一个默认值。用 `del d[key]` 删除一项。

```python run
tel = {"jack": 4098, "sape": 4139}
tel["guido"] = 4127
print(tel.get("irv"))  # None
```

`key in d` 检查字典是否包含这个键。`list(d)` 按插入顺序返回所有键。两个字典包含相同的键值对就相等，键的插入顺序可以不同。
