## 安装 uv

uv 是用 Rust 编写的 Python 包和项目管理工具。它可以下载 Python、创建虚拟环境，也负责安装依赖、锁定版本和运行项目命令。按你的操作系统选择下面的安装命令。

<TabsList aria-label="操作系统" className="rp-not-doc max-w-full flex-wrap justify-start">
  <TabsTrigger value="unix">macOS / Linux</TabsTrigger>
  <TabsTrigger value="windows">Windows（PowerShell）</TabsTrigger>

```bash
curl -LsSf https://astral.sh/uv/install.sh | sh
```

</TabsContent>
<TabsContent value="windows" markdownLabel="Windows（PowerShell）" className="min-w-0">

```powershell
powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
```

</TabsContent>
</Tabs>

uv 可以按项目需要下载 Python。想提前准备 Python 3.15，可以运行下面的命令。

```bash
uv python install 3.15
```

## 创建并运行项目

<Steps>

### 创建项目

```bash
uv init --python 3.15 tally
cd tally
```

`uv init` 生成项目骨架，并初始化一个 Git 仓库。

### 安装开发依赖

用 `uv add 包名` 添加运行时依赖，用 `uv remove 包名` 移除。添加开发工具时带上 `--dev`，uv 会把它们记入单独的 `dev` 依赖组。先安装本篇会用到的三个工具。

```bash
uv add --dev ruff ty pytest
```

### 首次运行

进入项目目录后，可以先运行一次项目入口。

```bash
uv run tally
# Hello from tally!
```

</Steps>

下面是 `uv init` 生成的 `pyproject.toml`，省略了作者信息。

```toml
[project]
name = "tally"
version = "0.1.0"
description = "Add your description here"
readme = "README.md"
requires-python = ">=3.15"
dependencies = []

[project.scripts]
tally = "tally:main"

[build-system]
requires = ["uv_build>=0.13.9,<0.14.0"]
build-backend = "uv_build"
```

`[project]` 存放标准的项目信息，其他打包工具也能读取。`requires-python` 声明支持的 Python 版本，`dependencies` 列出运行时依赖。`[project.scripts]` 定义入口命令。执行 `tally` 时，Python 会调用 `tally` 包里的 `main()`。

`pyproject.toml` 记录项目接受的依赖范围，`uv.lock` 记录锁定的版本。两个文件一起提交，团队就可以按同一份锁文件安装依赖。`.venv` 留在本地，必要时由 uv 重建。

`uv run` 会在执行命令前检查锁文件和项目环境，必要时先同步。平时可以直接用它运行项目命令，省去手动激活虚拟环境的步骤。

想升级某个依赖，可以用 `uv lock --upgrade-package 包名`。想临时运行一个命令行工具，可以用 `uvx`，例如 `uvx ruff check`。

## Ruff：格式与规范

Ruff 可以格式化代码，也可以检查代码。先用 `ruff format` 统一缩进、空格、引号和换行。它默认缩进 4 个空格，行宽目标为 88 个字符。长字符串等内容格式化后仍可能超过这个长度。

```bash
uv run ruff format
```

`ruff check` 可以发现未使用的导入、未定义的名字等问题。在 `pyproject.toml` 里还可以启用下面三组规则。

```toml
[tool.ruff.lint]
extend-select = ["I", "UP", "B"]
```

- `I` 把导入按标准库、第三方库和项目模块分组，也会给它们排序。分组方式见 5.1 节。
- `UP` 找出可以升级的写法。Ruff 根据 `requires-python` 推断目标版本，本项目是 3.15。
- `B` 检查容易踩的坑，例如 4.3 节讲的可变默认值。

```bash
uv run ruff check        # 列出问题
uv run ruff check --fix  # 自动修复其中安全的部分
```

## ty：类型检查

第 7 章介绍了类型标注。Python 运行代码时不会自动按标注检查实参。ty 会读取标注，提前指出类型传错、没有处理可能的 `None`、属性名拼错等问题。

```bash
uv run ty check
```

ty、uv 和 Ruff 都由 Astral 开发。ty 也能为编辑器提供补全、悬停提示和跳转。本篇使用的 ty 仍是 beta 版，诊断规则还可能变化。Pyright 和 mypy 也可以读取同一套类型标注。

## pytest：测试

先把统计词频的代码保存到 `src/tally/__init__.py`。每次调用 `count_words()` 都会创建自己的计数字典。

```python
def count_words(text: str) -> dict[str, int]:
    counts: dict[str, int] = {}
    for word in text.lower().split():
        counts[word] = counts.get(word, 0) + 1
    return counts


def main() -> None:
    print(count_words("the cat and the hat"))
```

把下面的代码保存到 `tests/test_tally.py`。文件名和函数名都以 `test_` 开头。用 `assert` 检查两个调用的返回值。

```python
from tally import count_words


def test_counts_each_word():
    assert count_words("a b a") == {"a": 2, "b": 1}


def test_ignores_case():
    assert count_words("Hi hi") == {"hi": 2}
```

在项目根目录运行测试。

```bash
uv run pytest
```

断言失败时，pytest 会显示实际结果和预期结果，并标出差异。

## 编辑器

把检查工具接到编辑器后，写代码时就能看到提示。这里用 VS Code 演示，需要安装三个扩展。

- **Python**（`ms-python.python`）识别项目里的 `.venv`，用它运行和调试代码。
- **Ruff**（`charliermarsh.ruff`）显示检查结果，也可以在保存时格式化。
- **ty**（`astral-sh.ty`）显示类型错误，并提供补全、悬停提示和跳转。它会自动停用 Python 扩展自带的语言服务器。

把下面的配置加入 `settings.json`，让 Ruff 在保存时格式化、自动修复并整理导入。

```json
{
  "[python]": {
    "editor.formatOnSave": true,
    "editor.codeActionsOnSave": {
      "source.fixAll": "explicit",
      "source.organizeImports": "explicit"
    },
    "editor.defaultFormatter": "charliermarsh.ruff"
  }
}
```
