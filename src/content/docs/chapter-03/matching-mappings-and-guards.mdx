映射模式按键取值。指定的键都必须存在，键对应的值也要符合相应的子模式。例如，`{"bandwidth": b, "latency": l}` 要求两个键都存在，并把它们的值分别绑定到 `b` 和 `l`。

映射模式会忽略额外的键。需要保留它们时，在模式末尾用 `**rest` 把额外的键值对收进一个字典。参见 [Python 3.15 的映射模式规则](https://docs.python.org/zh-cn/3.15/reference/compound_stmts.html#mapping-patterns)。

```python
match event:
    case {"bandwidth": b, "latency": l}:
        print(b, l)
    case {"type": kind, **rest}:
        print(kind, rest)
```

模式可以嵌套。比如 `("north" | "south") as direction` 可以匹配两个方向中的任意一个，再把匹配到的值绑定到 `direction`。

## 守卫

写在模式后面的 `if` 条件叫作守卫。Python 先匹配模式并绑定名字，再检查守卫。守卫为真就执行这个分支。守卫为假就继续尝试下一个 `case`。

```python run
order = {"id": "A101", "status": "paid", "amount": 120}
match order:
    case {"status": "paid", "amount": amount} if amount >= 100:
        print("VIP 订单")
    case {"status": "paid", "amount": _}:
        print("普通订单")
    case _:
        print("其他订单")
```

## 随堂练习

逐条遍历订单。匹配模式 `{"id": order_id, "status": "paid", "amount": amt}` 时，用守卫按金额划分订单等级。每条订单输出一行。

- 匹配上述模式且 `amt >= 100` 时，输出 `VIP 订单 {order_id}: 已付款 {amt} 元`。
- 其余匹配上述模式的订单，输出 `普通订单 {order_id}: 已付款 {amt} 元`。
- 其他订单输出 `其他订单`。
