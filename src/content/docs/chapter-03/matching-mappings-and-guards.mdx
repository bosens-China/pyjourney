映射模式按键取值。`{"bandwidth": b, "latency": l}` 把指定键的值分别绑定到 `b` 和 `l`。字典里可以有额外的键，默认会忽略它们。需要保留这些键值对时，可以用 `**rest` 收进一个字典。双星号后要写一个接收这些键值对的普通名字。

```python
match event:
    case {"bandwidth": b, "latency": l}:
        print(b, l)
    case {"type": kind, **rest}:
        print(kind, rest)
```

模式里还可以嵌套其他模式。`as` 把子模式匹配到的值绑定到一个名字。下面先用 `|` 匹配一个方向，再用 `as` 把方向绑定到 `direction`。

```python
match command.split():
    case ["go", ("north" | "south" | "east" | "west") as direction]:
        print("前往", direction)
```

## 守卫

写在模式后面的 `if` 条件叫作守卫。Python 先匹配模式并绑定名字，再检查守卫。守卫为真就执行这个分支。守卫为假就继续尝试下一个 `case`。

```python
match point:
    case (x, y) if x == y:
        print(f"在对角线上：{x}")
    case (x, y):
        print("不在对角线上")
```

## 随堂练习

逐条遍历订单。匹配模式 `{"id": order_id, "status": "paid", "amount": amt}` 时，用守卫区分两种金额。每条订单输出一行。

- 匹配上述模式且 `amt >= 100` 时，输出 `VIP 订单 {order_id}: 已付款 {amt} 元`。
- 其余匹配上述模式的订单，输出 `普通订单 {order_id}: 已付款 {amt} 元`。
- 其他订单输出 `其他订单`。
