映射模式从字典里取出指定的键。`{"bandwidth": b, "latency": l}` 把这两个键的值绑到 `b` 和 `l`。没有写出来的键被忽略；序列模式则要求项数对应，多出来的项不能悄悄丢掉。`**rest` 可以把其余键值对收进一个字典。`**_` 是多余的，不允许使用。

```python
match event:
    case {"bandwidth": b, "latency": l}:
        print(b, l)
    case {"type": kind, **rest}:
        print(kind, rest)
```

模式可以嵌套。`as` 给已经匹配的子模式再起一个名称，常和 `|` 一起用：

```python
match command.split():
    case ["go", ("north" | "south" | "east" | "west") as direction]:
        print("前往", direction)
```

## 守卫

模式后面可以写 `if`。匹配时先按模式捕获，再求守卫。守卫为假就放弃这个 `case`，继续尝试下一个。守卫为真才执行该分支。

```python
match point:
    case (x, y) if x == y:
        print(f"在对角线上：{x}")
    case (x, y):
        print("不在对角线上")
```

## 随堂练习

遍历订单列表，对每个订单按下面的顺序匹配：

- `{"id": order_id, "status": "paid", "amount": amt}` 并且 `amt >= 100` 时，输出 `VIP 订单 {order_id}: 已付款 {amt} 元`；
- 同样的键，但守卫不成立时，输出 `普通订单 {order_id}: 已付款 {amt} 元`；
- 其他订单输出 `其他订单`。
