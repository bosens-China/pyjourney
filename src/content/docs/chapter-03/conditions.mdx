## 条件

`if` 按条件选择分支。可以接多条 `elif`，依次检查其他条件，也可以用一条 `else` 处理剩余情况。条件按上一章的真值规则判断，例如空容器、零和 `None` 都是假值。

```python
score = 82
if score >= 90:
    grade = "A"
elif score >= 60:
    grade = "B"
else:
    grade = "C"
```

比较可以连写。`0 <= score < 100` 判断分数是否落在指定范围内，中间的 `score` 只求值一次。`in` 检查某一项是否存在，`not` 把真假翻转为布尔值。

`and` 遇到左侧是假值，就直接返回左侧。`or` 遇到左侧是真值，也直接返回左侧。其余情况下，它们会计算并返回右侧。例如，`name` 是空字符串时，`name or "匿名"` 会取右侧的默认名字。参见 [Python 3.15 的布尔运算规则](https://docs.python.org/zh-cn/3.15/builtins/stdtypes.html#boolean-operations-and-or-not)。

需要按条件从两个值中选一个时，可以用条件表达式。

```python
label = "及格" if score >= 60 else "不及格"
```

## 遍历元素

`for` 可以直接遍历序列和其他可迭代对象。每一轮，循环变量都绑定到当前取出的元素。

```python run
for word in ["cat", "window", "defenestrate"]:
    print(word, len(word))
```

用 `range(start, stop, step)` 可以按固定步长遍历整数，取值到 `stop` 之前为止。

同时需要编号和元素时，用 `enumerate()`。把几个序列的元素一一配对时，用 `zip()`。需要遍历字典的键和值时，用 `items()`。

```python run
names = ["Ada", "Bob"]
scores = [95, 78]

for i, name in enumerate(names, start=1):
    print(i, name)

for name, score in zip(names, scores, strict=True):
    print(name, score)

for name, score in {"Ada": 95, "Bob": 78}.items():
    print(name, score)
```

`zip()` 默认在最短的输入用完时停止。如果几组数据应该一一对应，可以传入 `strict=True`。遍历时发现长度不一致，Python 会引发 `ValueError`。

`sorted()` 把元素排好序，放进一个新列表。想反转排序方向时，传入 `reverse=True`。想直接从末尾开始遍历时，用 `reversed()`。

```python run
scores = [78, 95, 88]
print(sorted(scores))                # [78, 88, 95]
print(sorted(scores, reverse=True))  # [95, 88, 78]
```

需要在遍历时增删元素，可以遍历原容器的副本，或者把处理后的结果放进一个新容器。

## while、break 与 continue

`while` 在条件为真时反复执行循环体。`break` 结束当前所在的最内层循环。`continue` 跳过本轮剩余语句，进入下一轮。

```python run
remaining = 3
while remaining > 0:
    print(remaining)
    remaining -= 1
print("出发")
```

有时条件和循环体需要用到同一个结果。可以用赋值表达式 `:=`，也叫海象运算符。下面每轮截取最多两项，把切片绑定到 `batch`。只要切片非空，就打印这一批，再让 `names` 指向剩余名单。

```python run
names = ["Ada", "Bo", "Cy"]
while batch := names[:2]:
    print(batch)
    names = names[2:]
```

把赋值表达式直接用作 `if` 或 `while` 的整个条件时，可以省略括号。参见 [Python 3.15 的赋值表达式规则](https://docs.python.org/zh-cn/3.15/reference/expressions.html#assignment-expressions)。

## 循环的 else

`for` 和 `while` 都可以带 `else`，循环正常结束时才会执行它。下面查找以 A 开头的名字。找到时用 `break` 提前结束，遍历完仍没找到时，就在 `else` 里提示。

```python
for name in names:
    if name.startswith("A"):
        print("找到", name)
        break
else:
    print("没有以 A 开头的名字")
```
