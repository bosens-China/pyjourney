字符串是有顺序的序列。“第几个字符”对应一个位置，可以用索引读取。要一次取出一段文字，可以用切片指定范围。

## 用索引取一个字符

索引写在方括号里，从 0 开始。第一个字符的索引是 0，第二个字符的索引是 1。也可以从末尾数，索引 `-1` 表示最后一个字符，`-2` 表示倒数第二个字符。

```python
filename = "week-03.txt"
print(filename[0])   # w
print(filename[-1])  # t
```

用索引读出的单个字符，类型仍然是字符串。如果索引指向的位置超出了范围，Python 会报告 `IndexError`。可以用 `len(filename)` 查看字符数。

## 用切片取一段文字

`text[start:stop]` 从 `start` 开始取，到 `stop` 的前一个位置停止。你可以把这两个数字看作文字两侧的边界。省略起点就从开头取，省略终点就取到末尾。

```python
filename = "week-03.txt"
print(filename[:4])   # week
print(filename[5:7])  # 03
print(filename[8:])   # txt
```

`filename[5:7]` 取索引 5 和 6 的字符。索引 7 处的点号正好落在停止边界上。如果希望取到末尾，写 `filename[8:]`，只留起点和冒号即可。

## 清理和拆分文本

字符串的**方法**是可以在这个字符串上调用的操作。写法是先写字符串或它的名字，再写点号和方法名。比如 `title.strip()` 会去掉 `title` 两端的空白，返回清理后的字符串。中间的空格会保留。

```python
title = "  阅读 计划  "
clean_title = title.strip()
print(clean_title)  # 阅读 计划
```

如果一条文本用逗号隔开多项内容，可以调用 `split(",")`。它会得到一个列表，依次保存拆出的各段文本。下一节会讲如何读写列表。

```python
line = "小说,散文,诗歌"
print(line.split(","))  # ['小说', '散文', '诗歌']
```
