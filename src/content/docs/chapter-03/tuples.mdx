元组按固定顺序保存一组值。每个位置都可以对应一个含义。例如，可以用两个位置表示一条阅读记录，第一个放书名，第二个放页数。

## 创建和读取元组

常用的写法是用圆括号包住各个值，用逗号分隔。元组也属于序列，可以按索引取值。

```python
record = ("散文", 18)
print(record[0])  # 散文
print(record[1])  # 18
```

决定元组的是逗号。只有一个元素时也保留逗号，例如 `("散文",)`。写 `("散文")` 表示用圆括号包起来的一个字符串表达式。

元组创建后，各位置保存的元素保持固定。若读完后要增加页数，可以创建一个新元组，再把 `record` 绑定到新的记录。

```python
record = ("散文", 18)
record = (record[0], record[1] + 6)
print(record)  # ('散文', 24)
```

## 解包到多个名字

如果知道每个位置的含义，可以用多个名字接收元组中的值。这叫**解包**。普通解包要求左边的名字数量和右边的元素数量相同，顺序也一一对应。

```python
record = ("散文", 18)
title, pages = record
print(f"{title} {pages} 页")  # 散文 18 页
```

列表可以保存多条元组记录。对于下面的列表，`for` 每次取出一个二元组，再分别绑定给 `title` 和 `pages`。

```python
records = [("散文", 18), ("小说", 24)]
for title, pages in records:
    print(f"{title} {pages} 页")
```

列表负责组织多条记录，每个元组负责保存一条记录中的固定字段。
