要按数据的值或形状选择分支，可以用 `match`。Python 按顺序用每个 `case` 的模式检查要匹配的值，执行第一个匹配成功的分支。有的模式还可以从这个值里取出一部分，把它绑定到名字。所有模式都匹配失败时，程序继续执行 `match` 之后的语句。

可以直接用字面值来匹配。多个字面值可以用 `|` 连起来，匹配其中任何一个即可。`_` 是通配符，可以匹配任意值。`True`、`False` 和 `None` 各自只匹配对应的那个对象，其他字面值按值比较。

```python run
command = "?"
match command:
    case "help" | "?":
        print("显示帮助")
    case "quit":
        print("退出程序")
    case _:
        print("未知命令")
```

在模式里直接写一个普通名字，会匹配任意值并把它绑定到这个名字，这叫捕获模式。要匹配已有常量的值，用带点号的名字，比如 `Color.RED` 表示已有的颜色常量。

## 序列模式

序列模式和解包赋值的写法类似。`[x, y]` 和 `(x, y)` 都能匹配正好有两项的列表或元组，也能匹配长度为 2 的 `range`。遇到迭代器、`str`、`bytes` 或 `bytearray` 时，序列模式会匹配失败。参见 [Python 3.15 的序列模式规则](https://docs.python.org/zh-cn/3.15/reference/compound_stmts.html#sequence-patterns)。

`[x, y, *rest]` 和 `(x, y, *rest)` 都要求至少有两项，剩余的项收进列表 `rest`。把 `*rest` 换成 `*_` 可以匹配同样的序列，同时忽略剩余项。

```python
match point:
    case (0, 0):  # [!code highlight]
        print("原点")
    case (0, y):  # [!code highlight]
        print(f"Y={y}")
    case (x, y):  # [!code highlight]
        print(f"X={x}, Y={y}")
    case _:
        print("不是二维点")
```

`(0, y)` 要求第一项是 0，并把第二项绑定到 `y`。`(x, y)` 则把两项分别绑定到 `x` 和 `y`，就像解包赋值 `(x, y) = point`。第 7 章讲完数据类后，还会介绍怎样按类和属性匹配。
