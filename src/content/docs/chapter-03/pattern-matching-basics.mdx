把一个值与多个常量比较，或者按数据的形状拆开它时，用 `match`。它接受一个主语，依次和各个 `case` 的模式比较，只执行第一个匹配成功的分支，并且可以把组成部分绑定到名称。没有任何模式匹配时，不执行任何分支。

最简单的模式是字面值。`_` 是通配符，总会匹配。几个字面值可以用 `|` 放在同一个模式里。`True`、`False` 和 `None` 按标识号比较，其他字面值按相等比较。

```python
status = 404
match status:
    case 400:
        print("请求有误")
    case 401 | 403 | 404:
        print("无权访问")
    case _:
        print("其他错误")
```

不带点号的名称是捕获模式，会匹配任意值并把它绑定到这个名称。所以不能用普通变量名匹配一个已有的常量：它会被当成新的捕获目标，匹配一切。要匹配常量，名称里要带点号，例如 `Color.RED`。

## 序列模式

序列模式的形状和解包赋值相同。元组模式和列表模式含义相同，都能匹配任意序列，但不能匹配迭代器或字符串。`[x, y, *rest]` 和 `(x, y, *rest)` 与对应的解包赋值做同样的事。`*` 后面可以写 `_`，此时只要求序列至少有星号之前和之后那些项，剩余项不绑定。

```python
match point:
    case (0, 0):  # [!code highlight]
        print("原点")
    case (0, y):  # [!code highlight]
        print(f"Y={y}")
    case (x, y):  # [!code highlight]
        print(f"X={x}, Y={y}")
    case _:
        print("不是二维点")
```

`(0, y)` 把主语的第二项绑到 `y`。`(x, y)` 捕获两项，和 `(x, y) = point` 是同一类绑定。按类和属性匹配对象的写法，在第 7 章讲完数据类之后再介绍。
