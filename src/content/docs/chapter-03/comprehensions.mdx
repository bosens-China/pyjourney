列表推导式逐项计算，用结果组成一个新列表，也可以先按条件筛选。它把「建立空列表、循环、追加元素」缩成一个表达式。推导式（如下面的平方列表）把循环变量留在自己的作用域内。

方括号里先写要计算的表达式，再写 `for` 指定从哪里取值。后面还可以接 `for` 或 `if`，顺序和嵌套循环里相同。直接写元组时，用圆括号把逗号分隔的各项括起来，例如 `(x, y)`。

```python
squares = [x**2 for x in range(10)]
pairs = [(x, y) for x in [1, 2, 3] for y in [3, 1, 4] if x != y]
flat = [num for elem in [[1, 2], [4, 5]] for num in elem]
```

下面的循环也会得到相同的 `flat`。外层逐个取子列表，内层再把子列表中的数逐项追加到 `flat`。

```python
flat = []
for elem in [[1, 2], [4, 5]]:
    for num in elem:
        flat.append(num)
```

集合推导式用花括号包住表达式，重复元素只保留一个。字典推导式也用花括号，冒号左边计算键，右边计算值。

```python
vowels = {letter for letter in "pineapple" if letter in "aeiou"}
squares_by_n = {x: x**2 for x in (2, 4, 6)}
```

推导式适合按条件筛选元素，或把每一项转成新值。如果需要嵌套好几层，或者每轮要执行多条语句，普通循环更好读。

## 生成器表达式

把列表推导式的方括号换成圆括号，就得到生成器表达式。它按需逐项产生结果，所以可以直接交给 `sum()`、`max()`、`any()` 或 `all()`。作为函数的唯一参数时，可以省掉表达式自己的圆括号。

```python
prices = [12, 48, 7]
print(sum(p * 2 for p in prices))    # 134
print(any(p > 40 for p in prices))   # True，有一项大于 40
print(all(p > 5 for p in prices))    # True，每一项都大于 5
```

`any()` 遇到第一个真值就停下，`all()` 遇到第一个假值就停下。输入为空时，`any([])` 得到 `False`，`all([])` 得到 `True`。生成器的工作方式在第 8 章细讲。参见 [Python 3.15 的内置函数说明](https://docs.python.org/zh-cn/3.15/builtins/functions.html#any)。

## 推导式里的解包

可以在列表、集合推导式和生成器表达式里用 `*` 展开各项，也可以在字典推导式里用 `**` 展开键值对。

```python
lists = [[1, 2], [3, 4], [5]]
[*L for L in lists]  # 等价于 [x for L in lists for x in L]

sets = [{1, 2}, {2, 3}, {3, 4}]
{*s for s in sets}  # 等价于 {x for s in sets for x in s}

dicts = [{"a": 1}, {"b": 2}, {"a": 3}]
{**d for d in dicts}  # 等价于 {k: v for d in dicts for k, v in d.items()}
```

上面三个推导式依次得到 `[1, 2, 3, 4, 5]`、`{1, 2, 3, 4}` 和 `{'a': 3, 'b': 2}`。字典里的键 `"a"` 写入两次，最后一次写入的 `3` 会留下。

生成器表达式 `(*L for L in lists)` 和 `(x for L in lists for x in L)` 会按相同顺序产生各项。
