## 标识号、类型和值

每个对象在存在期间都有固定的标识号，可用 `id()` 查看。`is` 检查两边是不是同一个对象，`==` 比较两边的值。`type()` 则返回对象的类型。

`a = []` 和 `b = []` 各建了一个空列表。两个列表内容相同，所以 `a == b` 为真。它们是两个对象，所以 `a is b` 为假。解释器可能复用整数、字符串等不可变对象，要比较它们的值时，用 `==`。参见 [Python 3.15 对象模型](https://docs.python.org/zh-cn/3.15/reference/datamodel.html#objects-values-and-types)。

列表和字典是可变容器，里面的项可以替换。元组是不可变容器，每个位置固定指向原来的对象。如果某个位置放的是列表，这个列表仍能修改。

字符串也是不可变对象。下面先拼出新字符串，再把名字 `s` 绑定到它。

```python run
s = "py"
t = s
s = s + "thon"
print(t)  # py
print(s)  # python
```

## 需要副本时

列表和字典都可以用 `copy()` 创建副本。这种复制叫浅层复制。它创建了一个新容器，里面的项仍指向原来的对象。需要一并复制嵌套的可变对象时，用 `copy.deepcopy()`。

```python run
original = [[1]]
copied = original.copy()
original[0].append(2)
print(copied)  # [[1, 2]]
```
