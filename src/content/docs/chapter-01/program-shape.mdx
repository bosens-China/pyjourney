下面两条语句从上往下执行。`print()` 默认用空格隔开各个参数，并在输出末尾换行。

```python
print("你好，Python")
print("1 + 2 =", 1 + 2)
```

```text
你好，Python
1 + 2 = 3
```

在字符串外，`#` 到行末的文字是注释。注释是给读代码的人看的，可以单独写一行，说明代码为什么这样写。字符串里的 `#` 会照常保留。

```python
# 运费按件计算
fee = 12  # 单位：元
print("# 不是注释")
```

## 缩进就是代码块

`if`、`for`、`def` 等语句用冒号引出代码块。块内同一层的语句从同一列开始，每一层缩进用 4 个空格。缩进退回外层时，当前代码块结束。

```python
total = 120
if total >= 100:
    print("满 100 元")  # [!code highlight]
    print("免运费")    # [!code highlight]
print("结算完成")
```

最后一行和 `if` 对齐，已经回到外层。所以条件无论真假，程序都会打印「结算完成」。第 3 章会详细讲条件判断和循环。

## 名字与赋值

`=` 先计算右边，再把结果绑定到左边的名字。例如，`count = count + 1` 先读出 `count` 的旧值并加 1，再把结果绑定回 `count`。给整数计数器加 1 时，通常用增强赋值 `count += 1`。读取尚未绑定的名字会引发 `NameError`。

一次赋值也可以绑定多个名字。`width, height = 20, 45` 把 `width` 绑定到 20，把 `height` 绑定到 45。这种写法叫元组解包，下一章会详细介绍。

## 命名与风格

下面是 PEP 8 风格指南里的几条常用约定。

- 变量和函数用小写加下划线，例如 `total_count`、`load_config`。
- 类用首字母大写的驼峰式，例如 `OrderItem`。
- 写 `area = width * height` 时，在赋值号和乘号两边留一个空格。逗号后也留一个空格。
- 用空行分隔函数、类和函数里较大的代码块。

名字要说明用途。`total_count` 比 `tc` 好读，`items` 比 `lst` 好读。
