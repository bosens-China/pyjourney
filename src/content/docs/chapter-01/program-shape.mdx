一个 Python 程序就是一串语句，解释器从上往下逐条执行。`print()` 是内置函数，把参数输出成一行文本，多个参数之间用空格隔开：

```python
print("你好，Python")
print("1 + 2 =", 1 + 2)
```

```text
你好，Python
1 + 2 = 3
```

`#` 到这一行末尾是注释，解释器不执行它。字符串里的 `#` 只是一个字符。注释最好单独占一行，说明代码为什么这样写。

```python
# 运费按件计算
fee = 12  # 单位：元
print("# 不是注释")
```

## 缩进就是代码块

以冒号结尾的语句头，例如 `if`、`for`、`def`，后面跟着一个代码块。Python 不用花括号，而是用缩进划出这个块：同一块里的每一行缩进相同，缩进结束，块也就结束了。缩进用 4 个空格，不用制表符。

```python
total = 120
if total >= 100:
    print("满 100 元")  # [!code highlight]
    print("免运费")    # [!code highlight]
print("结算完成")
```

最后一行没有缩进，它不属于 `if`，无论条件真假都会执行。条件判断和循环在第 3 章细讲，这里只需要认出缩进的作用。

## 名字与赋值

`=` 把右边的值绑定到左边的名字。右边先求值，再绑定，所以 `count = count + 1` 是先读出旧值、算出新值，再让 `count` 指向新值。它通常写成增强赋值 `count += 1`。还没有绑定的名字不能读取，读取会引发 `NameError`。

一行里可以同时绑定几个名字：`width, height = 20, 45`。下一章会看到，这其实是元组解包。

## 命名与风格

Python 社区普遍遵循 PEP 8 风格指南：

- 变量和函数用小写加下划线，例如 `total_count`、`load_config`。
- 类用首字母大写的驼峰式，例如 `OrderItem`。
- 运算符两边、逗号后面各留一个空格：`area = width * height`。
- 用空行分隔函数、类和函数里较大的代码块。

名字要说明用途。`total_count` 比 `tc` 好读，`items` 比 `lst` 好读。
