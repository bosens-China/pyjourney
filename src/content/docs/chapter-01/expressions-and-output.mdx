表达式是一段可以求出值的代码。得到这个值的过程叫求值。例如，`2 + 3` 的求值结果是整数 `5`。对一个已经绑定的名字求值，会得到这个名字当前指向的值。

## 表达式与赋值语句

在 `total = 2 + 3` 这条赋值语句中，右边的 `2 + 3` 是表达式。Python 先算出 `5`，再让 `total` 指向这个结果。后续代码可以通过这个名字使用计算结果。

```python
total = 2 + 3
print(total)  # 5
```

表达式也可以直接放在 `print()` 的括号里。例如，`print(2 + 3)` 会先计算再输出 `5`。

## 算术运算与优先级

Python 常用的四个算术运算符是 `+`、`-`、`*` 和 `/`。

| 表达式  | 运算 | 求值结果 |
| ------- | ---- | -------- |
| `8 + 3` | 加法 | `11`     |
| `8 - 3` | 减法 | `5`      |
| `8 * 3` | 乘法 | `24`     |
| `8 / 2` | 除法 | `4.0`    |

用 `/` 对两个整数做除法，即使能整除，结果也是浮点数。因此 `8 / 2` 的结果显示为 `4.0`。

在算式中，乘法和除法的优先级高于加法和减法。圆括号可以把其中的表达式作为一个整体，让 Python 先求出这个整体的值。

```python
print(2 + 3 * 4)    # 14
print((2 + 3) * 4)  # 20
```

第一行先算 `3 * 4`，再加上 `2`。第二行先算出括号里的 `5`，再乘以 `4`。

## 用 f-string 把值写进文本

在字符串的开头引号前写一个 `f`，就能在大括号 `{}` 中嵌入表达式。这样的字符串写法叫 f-string。Python 先对大括号中的表达式求值，再把结果填进文本。

```python
count = 3
print(f"数量为 {count}")        # 数量为 3
print(f"加一后为 {count + 1}")  # 加一后为 4
```

大括号里可以直接写变量名，例如 `{count}`。需要做一次计算时，也可以写出算式，例如 `{count + 1}`。

## 控制数字的显示格式

在大括号内，冒号把要计算的表达式和格式说明分开。例如，`{fraction:.2f}` 会将 `fraction` 的值显示为两位小数。

要把比例显示成百分比，可以用 `%` 格式。它会把数值乘以 100，再按指定的小数位数舍入并附上百分号。`.0%` 省去小数位，`.1%` 显示一位小数。

```python
fraction = 1 / 6
print(f"{fraction:.2f}")  # 0.17
print(f"{fraction:.0%}")  # 17%
print(f"{fraction:.1%}")  # 16.7%
```

三条输出使用的是同一个数值。舍入发生在生成文本时，`fraction` 仍保留着原来的计算结果。
