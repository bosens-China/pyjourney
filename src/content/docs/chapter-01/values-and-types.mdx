下面两行都会输出 `18`。第一行传给 `print()` 的是整数，第二行传给它的是一段文本。

```python
print(18)
print("18")
```

一个值的**类型**告诉 Python 可以怎样使用它。对两个整数用 `+`，Python 做加法。对两个字符串用 `+`，Python 把它们接成一段更长的文本。

```python
print(18 + 6)      # 24
print("18" + "6")  # 186
```

## 常见的值

| 例子             | 类型              | 含义或用途         |
| ---------------- | ----------------- | ------------------ |
| `18`、`0`        | `int`（整数）     | 表示整数，适合计数 |
| `0.5`、`2.0`     | `float`（浮点数） | 表示可含小数的数值 |
| `"Python"`、`""` | `str`（字符串）   | 表示文本           |
| `True`、`False`  | `bool`（布尔值）  | 表示真和假         |
| `None`           | `NoneType`        | 常用来表示值缺失   |

选择什么值，取决于你想表达的意思。例如，`0` 可以表示计数结果为零，`""` 表示长度为零的文本，`None` 可以表示这一项还没有值。

## 查看类型

要区分开头两行代码里的值，可以先用 `type()` 查看类型，再用 `print()` 显示查看结果。

```python
print(type(18))
print(type("18"))
```

```text
<class 'int'>
<class 'str'>
```

输出中的 `int` 和 `str` 就是这两个值的类型名称。

## 把数字文本转换成整数

如果得到的值是字符串 `"18"`，可以用 `int("18")` 转换成整数 `18`。有了整数，就可以用它继续做计算。

```python
print(int("18") + 6)  # 24
```

这行代码先调用 `int()` 完成转换，再用转换后的整数与 `6` 相加。
