一行代码就可以组成一个 Python 程序。执行下面这行代码，程序会输出一行文字。

```python
print("你好，Python")
```

```text
你好，Python
```

上面第一块是要执行的**源代码**，第二块是执行后看到的**输出**。后面的例子也用这种方式展示代码和结果。

## 看懂这一行代码

`print` 是 Python 自带的函数，用来输出内容。写上圆括号，并把要输出的内容放在里面，就是一次对 `print` 的调用。

`"你好，Python"` 是一个**字符串**，也就是代码里用来表示文本的值。双引号标出文本的范围。这次调用输出的就是引号里的文字。

## 执行多行代码

可以把两次调用分别写在两行里。Python 在这段程序里从上往下执行，先输出“第一行”，再输出“第二行”。

```python
print("第一行")
print("第二行")
```

```text
第一行
第二行
```

每次调用 `print()` 默认会在输出末尾换行，所以这两条内容各占一行。交换两行代码，输出的顺序也会随之交换。

## 用注释写下说明

代码里也可以留一句给人看的说明。在字符串之外，`#` 到这一行末尾的内容叫作**注释**。Python 执行代码时会忽略注释。

```python
# 输出问候语
print("你好")
```

```text
你好
```
