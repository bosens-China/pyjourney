程序运行到一半时，可能遇到无法继续的操作。例如，`int("缺考")` 无法把这段文本转换为整数，Python 会引发 `ValueError`。异常可以由代码处理。异常一路传出程序时，Python 会显示错误信息和回溯。

## 先读最后一行

把下面的代码保存为 `score.py`，再用 Python 运行。

```python
def read_score(text):
    return int(text)

score = read_score("缺考")
print(score)
```

回溯的路径因运行位置而异。省略目录后，输出如下。

```text
Traceback (most recent call last):
  File "score.py", line 4, in <module>
    score = read_score("缺考")
            ~~~~~~~~~~^^^^^^^^
  File "score.py", line 2, in read_score
    return int(text)
ValueError: invalid literal for int() with base 10: '缺考'
```

先看最后一行。`ValueError` 是异常类型。后面的信息给出了导致转换失败的值 `'缺考'`。这一行能帮你决定下一步要检查什么。

## 顺着调用位置找到输入

接着看靠近底部的代码位置。第 2 行调用了 `int(text)`，这里是异常发生的位置。往上看第 4 行，就能知道 `text` 来自 `read_score("缺考")`。

现在可以从两个地方着手。如果这里应该传入分数，就检查数据来源。如果“缺考”是允许出现的记录，就在读取分数时明确处理这种情况。

## 从异常类型判断方向

| 异常         | 常见原因                                   | 示例                        |
| ------------ | ------------------------------------------ | --------------------------- |
| `ValueError` | 参数属于可接受的类型，但值无法用于这项操作 | `int("缺考")`               |
| `TypeError`  | 操作用到了不支持的类型                     | `"3" + 2`                   |
| `KeyError`   | 字典缺少要查的键                           | `{"name": "阿文"}["score"]` |

语法错误出现在 Python 解析代码时。例如，`if` 语句末尾遗漏冒号会引发 `SyntaxError`。遇到这种情况，先检查错误信息指向的代码和相邻行。
