最常见的 `with` 是打开文件：

```python
with open("notes.txt", encoding="utf-8") as f:
    text = f.read()
```

不管代码块是正常结束、`return` 出去，还是中途引发异常，离开 `with` 时文件都会被关闭。凡是「用完必须归还」的资源，例如文件、锁和网络连接，都应该这样用。

`with` 后面的对象是上下文管理器。它的协议只有两个方法：

1. 进入时调用 `__enter__()`，有 `as` 时把它的返回值绑定到目标。`__enter__` 正常返回之后，离开时就一定会调用 `__exit__`。
2. 离开时调用 `__exit__(exc_type, exc_value, traceback)`。代码块因异常离开时，三个参数描述这个异常；否则都是 `None`。

异常离开时，`__exit__` 返回假值（包括什么都不返回），异常继续向外传播；返回真值，异常被抑制，接着执行 `with` 后面的语句。只在确实打算吞掉异常时才返回真值。

下面的管理器在代码块出错时把字典恢复成进入时的内容：

```python
class Edit:
    def __init__(self, store):
        self.store = store

    def __enter__(self):
        self._saved = dict(self.store)
        return self.store

    def __exit__(self, exc_type, exc, tb):
        if exc_type is not None:
            self.store.clear()
            self.store.update(self._saved)
        return False

store = {"n": 1}
with Edit(store) as current:
    current["n"] = 2
print(store["n"])
```

没有异常时，`store["n"]` 保持 `2`。若代码块里抛出异常，`__exit__` 先把字典恢复成进入时的内容，再返回假值，异常继续向外走。

多个项目按嵌套的 `with` 处理：`with A() as a, B() as b` 就是进入 `A` 之后再进入 `B`，离开时先退出 `B` 再退出 `A`。
