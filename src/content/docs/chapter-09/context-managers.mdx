读取文件时，常把 `open()` 放进 `with`。

```python
with open("notes.txt", encoding="utf-8") as f:
    text = f.read()
```

在 `with` 代码块里，可以通过 `f` 读取文件。代码块正常结束、通过 `return` 离开或引发异常时，`with` 都会关闭文件。其他用完就要释放的资源，例如锁，也适合用 `with` 管理。

`with` 后面的对象叫上下文管理器。它提供两个方法。

1. 进入时，Python 调用 `__enter__()`。如果写了 `as`，返回值就绑定到 `as` 后面的目标。
2. 只要 `__enter__()` 正常返回，离开时 Python 就会调用 `__exit__(exc_type, exc_value, traceback)`。发生异常时，三个参数描述这个异常。正常离开时，它们都是 `None`。

代码块因异常中断时，`__exit__` 的返回值决定接下来怎么走。返回假值（包括默认的 `None`），异常就会继续传播。返回真值，Python 会抑制异常，接着执行 `with` 之后的语句。

下面的 `Edit` 在进入时保存字典的键值对。代码块出错时，它用保存的键值对恢复字典。

```python
class Edit:
    def __init__(self, store):
        self.store = store

    def __enter__(self):
        self._saved = dict(self.store)
        return self.store

    def __exit__(self, exc_type, exc, tb):
        if exc_type is not None:
            self.store.clear()
            self.store.update(self._saved)
        return False

store = {"n": 1}
with Edit(store) as current:
    current["n"] = 2
print(store["n"])
```

代码块正常结束时，`store["n"]` 保持为 `2`。如果代码块引发异常，`__exit__` 会恢复字典并返回 `False`，异常继续向外传播。

一个 `with` 里可以写多个上下文管理器，效果和嵌套写法一样。`with A() as a, B() as b` 会先进入 `A`，再进入 `B`。退出顺序相反，先离开 `B`，再离开 `A`。
