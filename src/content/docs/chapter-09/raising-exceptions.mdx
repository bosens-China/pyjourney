函数有时能得到一个值，却无法用它完成任务。例如，`-3` 可以转换成整数，可库存数量要求大于或等于零。函数可以用 `raise` 主动引发异常，让调用方决定如何处理。

## 把处理规则写在发现问题的地方

```python
def parse_quantity(text):
    quantity = int(text)
    if quantity < 0:
        raise ValueError("库存数量必须大于或等于零")
    return quantity

try:
    quantity = parse_quantity("-3")
except ValueError as error:
    print(error)  # 库存数量必须大于或等于零
```

`int(text)` 负责把文本转换为整数，`if` 负责检查库存的业务规则。只要这两步有一步引发 `ValueError`，调用方都能按无效输入处理。

`except ValueError as error` 会把捕获到的异常绑定给 `error`。当程序需要显示具体原因时，可以把这个对象交给 `print()`。

## 用 finally 完成收尾

`finally` 中的代码在退出 `try` 语句前执行。无论受保护的操作成功、提前返回还是引发异常，`finally` 都会执行。

```python
def parse_once(text):
    try:
        return int(text)
    finally:
        print("本次转换结束")

print(parse_once("8"))

try:
    parse_once("待定")
except ValueError:
    print("转换失败")
```

输出如下。

```text
本次转换结束
8
本次转换结束
转换失败
```

第一次调用在返回整数之前执行了收尾代码。第二次调用先完成收尾，异常随后传给外层的 `except`。这适合释放资源或记录操作结束。对文件这类提供专门管理方式的资源，后续可以用 `with` 写出同样清楚的生命周期。
