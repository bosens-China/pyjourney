从表单或文件读来的数据常常是文本。遇到一条无法转换的内容时，程序可以标记这条记录，再继续处理其他记录。用 `try` 包住可能失败的操作，用 `except` 写下应对办法。

## 把可能失败的操作放进 try

```python
for text in ["12", "待定", "7"]:
    try:
        number = int(text)
    except ValueError:
        print(f"跳过 {text}")
        continue

    print(number)
```

输出如下。

```text
12
跳过 待定
7
```

转换成功时，Python 跳过 `except`，继续执行后面的代码。转换引发 `ValueError` 时，Python 进入对应的 `except`，然后用 `continue` 开始下一轮循环。

## 缩小捕获范围

把 `try` 限定在准备处理的操作上。上例只把 `int(text)` 放在其中，处理规则也限定为 `ValueError`。如果后面计算或输出的代码出现问题，回溯就会保留这个问题的线索。

需要在转换成功后执行一段代码时，可以用 `else`。异常处理和成功分支并排，读者容易看出两条路径。

```python
text = " 12 "

try:
    count = int(text)
except ValueError:
    print("请输入整数")
else:
    print(f"数量为 {count}")  # 数量为 12
```
