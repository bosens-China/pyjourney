函数可以像其他对象一样传给另一个函数（第 4 章）。装饰器接收原函数，通常会返回一个新的包装函数。有了这个包装，就能在调用原函数前后记录日志、统计耗时。

Python 在定义函数时求值 `def` 上方的 `@表达式`。求值结果必须可以调用，Python 会把原函数作为参数传给它，再把返回值绑定到函数名。

```python
@log
def greet():
    return "hi"
```

上面的 `greet` 最终绑定的是 `log` 的返回值。

## 叠加装饰器

写了多个装饰器时，Python 先求值各个 `@` 后面的表达式，再应用得到的装饰器。离 `def` 最近的装饰器先接收原函数。

```python
@f1(arg)
@f2
def func():
    pass
```

## functools.wraps

给包装函数加上 `@functools.wraps(fn)`，就能保留原函数的名字、模块名和文档字符串。需要访问原函数时，可以从包装函数的 `__wrapped__` 属性取得。

```python run
import functools

def log_call(fn):
    @functools.wraps(fn)
    def wrapper(*args, **kwargs):
        print(f"调用函数: {fn.__name__}")
        return fn(*args, **kwargs)
    return wrapper

@log_call
def add(a, b):
    """计算两数之和。"""
    return a + b

print(add.__name__)
print(add.__doc__)
```

两次 `print` 依次打印原函数名 `add` 和文档字符串「计算两数之和。」。
