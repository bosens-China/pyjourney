函数是对象，可以当参数传、当返回值返回（第 4 章）。装饰器就建立在这一点上：它是一个接收函数、返回新函数的可调用对象，用来在不改动原函数的情况下给它加上日志、计时、缓存、权限检查这类外围行为。

`def` 上面的 `@表达式` 在定义函数时求值。Python 用刚创建的函数对象调用它，再把返回值绑到函数名上。因此：

```python
@log
def greet():
    return "hi"
```

大致等价于先执行 `def`，再执行 `greet = log(greet)`。多个装饰器嵌套应用，靠近 `def` 的那一个先包进去：

```python
@f1(arg)
@f2
def func():
    pass
```

大致等价于 `func = f1(arg)(f2(func))`。`f1(arg)` 先调用、返回真正的装饰器，这就是带参数的装饰器。

## functools.wraps

装饰之后，名字指向的是包装函数，它自己的名字和文档字符串会盖住原函数。写装饰器时总是给包装函数加上 `functools.wraps(fn)`：它把原函数的名字、模块和文档字符串复制过来，并用 `__wrapped__` 留下原函数。

```python
import functools

def log_call(fn):
    @functools.wraps(fn)
    def wrapper(*args, **kwargs):
        print(f"调用函数: {fn.__name__}")
        return fn(*args, **kwargs)
    return wrapper

@log_call
def add(a, b):
    """计算两数之和。"""
    return a + b

print(add.__name__)
print(add.__doc__)
```

输出是 `add` 和 `计算两数之和。`。

`count_calls` 每调用一次就打印次数。`wraps` 让装饰之后的 `ping.__name__` 和文档字符串仍是原函数的。
