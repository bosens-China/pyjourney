类主要用来存储数据时，可以用 `@dataclass`。这一行根据字段声明生成 `__init__`、`__repr__` 和 `__eq__`。比如 `x: int` 声明了字段 `x`，并标注它的类型为整数。这个标注供读者和工具参考，[类型标注](./type-aliases.mdx)一节会说明怎么写。需要其他操作时，照常定义方法即可。

```python run
from dataclasses import dataclass

@dataclass
class Point:
    x: int
    y: int

    def moved(self, dx, dy):
        return Point(self.x + dx, self.y + dy)

p = Point(1, 2)
print(p.moved(3, 4))     # Point(x=4, y=6)
print(p == Point(1, 2))  # True
```

## 默认值与 default_factory

把有默认值的字段写在没有默认值的字段后面。列表、字典这样的可变默认值用 `field(default_factory=...)` 声明。创建实例时如果需要默认值，Python 会调用工厂函数。用 `list` 作工厂函数，每次都会得到一个新列表。

```python run
from dataclasses import dataclass, field

@dataclass
class Article:
    title: str
    views: int = 0
    tags: list[str] = field(default_factory=list)

a = Article("入门")
b = Article("进阶")
a.tags.append("python")
print(a.tags, b.tags)  # ['python'] []
```

## 创建后固定字段

坐标、金额这类表示一个值的对象，通常在创建后就固定下来。设定 `frozen=True` 后，对字段赋值或删除字段都会引发 `FrozenInstanceError`。

同时保留默认的 `eq=True` 时，数据类会根据字段生成 `__hash__`。要把实例放进集合或用作字典的键，参与哈希计算的字段也必须可哈希。如果某个字段存的是列表，列表内容仍然可以修改，计算这个字段的哈希会引发 `TypeError`。

```python run
from dataclasses import dataclass

@dataclass(frozen=True)
class Money:
    amount: int
    currency: str = "CNY"

print(Money(5))
```

## 在 match 里拆开对象

第 3 章的模式匹配也能按类和属性匹配对象。`Point(x=0, y=y)` 先检查对象是否为 `Point` 的实例，再检查属性 `x` 是否等于 `0`。匹配成功后，把属性 `y` 的值绑定到名字 `y`。等号左边指定要查看的属性。

示例中的 `Point` 还支持按位置匹配。字段按 `x`、`y` 的顺序定义，所以可以把这个模式简写为 `Point(0, y)`。

```python
match point:
    case Point(0, 0):
        print("原点")
    case Point(0, y):
        print(f"在 y 轴上，y={y}")
    case Point(x, y) if x == y:
        print(f"在对角线上：{x}")
    case Point():
        print("别处的点")
```

## 排序与实例存储（选读）

需要按字段比较大小时，可以加上 `order=True`。同类的两个实例会像元组一样，按字段声明的顺序比较。`slots=True` 则为字段生成 `__slots__`，适合在需要控制实例存储方式时使用。更多选项见 [`dataclass` 官方文档](https://docs.python.org/zh-cn/3.15/library/dataclasses.html#dataclasses.dataclass)。
