类把数据和对这些数据的操作放在一起。执行 `class` 语句会创建一个类对象，并把它绑定到类名上。调用类对象就创建一个实例；类定义了 `__init__` 时，Python 会立刻用调用时给出的参数调用它，完成初始化。

## 实例方法与 self

类体里的 `def` 定义方法。通过实例调用方法时，实例会作为第一个参数传进去，按约定这个参数叫 `self`：`counter.bump()` 相当于 `Counter.bump(counter)`。

`self.value = start` 把属性写在这个实例上，每个实例各有一份。直接写在类体里的赋值是类属性，所有实例共享，适合放常量。

```python
class Counter:
    step = 1

    def __init__(self, start=0):
        self.value = start

    def bump(self):
        self.value += self.step
        return self.value

counter = Counter(1)
print(counter.bump())  # 2
```

## 特殊方法

名字前后各有两个下划线的方法是特殊方法，Python 在特定场合自动调用它们。最常写的三个：

- `__init__`：创建实例后初始化。
- `__repr__`：返回对象的表示形式，`repr()`、交互式解释器和调试输出都用它。最好让它看起来像创建这个对象的表达式。没有定义 `__str__` 时，`print()` 也用它。
- `__eq__`：定义 `==`。不定义时，两个实例只有是同一个对象才相等。

```python
class Money:
    def __init__(self, amount, currency="CNY"):
        self.amount = amount
        self.currency = currency

    def __repr__(self):
        return f"Money({self.amount!r}, {self.currency!r})"

    def __eq__(self, other):
        if not isinstance(other, Money):
            return NotImplemented
        return (self.amount, self.currency) == (other.amount, other.currency)

print(Money(5))              # Money(5, 'CNY')
print(Money(5) == Money(5))  # True
```

`__eq__` 遇到不认识的类型时返回 `NotImplemented`，让 Python 去试另一边的比较。像 `Money` 这样以字段为主的类，下一课的数据类会自动生成这几个方法。

## property

属性的值需要计算，或者赋值时需要检查，就用 `@property`。调用方仍然像读写普通属性一样使用它：

```python
class Temperature:
    def __init__(self, celsius):
        self.celsius = celsius

    @property
    def fahrenheit(self):
        return self.celsius * 9 / 5 + 32

t = Temperature(100)
print(t.fahrenheit)  # 212.0
```

所以一开始直接用公开属性就好，不必为每个属性写取值和设值的方法；以后需要加计算或检查时，再换成 `property`，调用代码不用改。只供类内部使用的名字以一个下划线开头，例如 `self._cache`。

## 继承与 super()

派生类把基类写在类名后面的括号里。查找属性时，当前类没有这个名字，就到基类里找。派生类可以写同名方法来覆盖基类；覆盖之后还要沿用基类的实现时，调用 `super()`：

```python
class LoudCounter(Counter):
    def bump(self):
        value = super().bump()
        print("现在是", value)
        return value
```

`super().bump()` 调用的是基类的 `bump`，`self` 会自动传入。`__init__` 里也一样：派生类的 `__init__` 先 `super().__init__(...)`，再设置自己的属性。`isinstance(obj, cls)` 在 `obj` 的类是 `cls` 或其派生类时为真。

继承表示「是一种」。只是想用另一个对象的功能时，把它存成属性（组合）通常比继承更简单。
