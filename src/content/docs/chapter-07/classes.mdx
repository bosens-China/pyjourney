类把数据和操作这些数据的方法放在一起。执行 `class` 语句时，Python 创建类对象，再把类名绑定到这个对象。调用类可以创建实例。如果类定义了 `__init__`，Python 会把调用时提供的参数交给它，用来初始化新实例。

## 实例方法与 self

在类体里用 `def` 定义实例方法。通过实例调用方法时，Python 把实例作为第一个参数传入，按约定这个参数叫 `self`。下面的 `counter.bump()` 相当于 `Counter.bump(counter)`。

`self.value = start` 给当前实例设置 `value`，每个实例各有一份。直接写在类体里的 `step` 是类属性，供各个实例共用。

```python run
class Counter:
    step = 1

    def __init__(self, start=0):
        self.value = start

    def bump(self):
        self.value += self.step
        return self.value

counter = Counter(1)
print(counter.bump())  # 2
```

## 特殊方法

特殊方法的名字前后各有两个下划线。Python 会在创建实例、比较对象等特定场合调用它们。

- `__init__` 在实例创建后初始化它。
- `__repr__` 返回对象的表示形式，供 `repr()`、交互式解释器和调试输出使用。合适时，可以把它写成创建该对象的表达式。类未定义 `__str__` 时，`print()` 也会用这个表示形式。
- `__eq__` 定义 `==` 的行为。沿用 `object` 的默认比较时，同一个对象才相等。

```python run
class Money:
    def __init__(self, amount, currency="CNY"):
        self.amount = amount
        self.currency = currency

    def __repr__(self):
        return f"Money({self.amount!r}, {self.currency!r})"

    def __eq__(self, other):
        if not isinstance(other, Money):
            return NotImplemented
        return (self.amount, self.currency) == (other.amount, other.currency)

print(Money(5))              # Money(5, 'CNY')
print(Money(5) == Money(5))  # True
```

自定义的 `__eq__` 通常返回 `True` 或 `False`。如果它不支持与对方的类型比较，就返回 `NotImplemented`，让 Python 尝试对方的比较方法。像 `Money` 这样以字段为主的类，可以用数据类生成这些方法。

## property

属性的值需要计算时，可以用 `@property`。下面的 `fahrenheit` 由 `celsius` 换算而来，读取时只要写 `t.fahrenheit`。

```python run
class Temperature:
    def __init__(self, celsius):
        self.celsius = celsius

    @property
    def fahrenheit(self):
        return self.celsius * 9 / 5 + 32

t = Temperature(100)
print(t.fahrenheit)  # 212.0
```

一开始可以直接用公开属性。以后需要在读取时计算，或在赋值时检查，再用 `property` 加上相应逻辑，调用方仍然用属性语法。准备留给类内部使用的属性通常以一个下划线开头，例如 `self._cache`。

## 继承与 super()

定义派生类时，把基类写在类名后面的括号里。派生类可以继承基类的方法，也可以用同名方法覆盖它。覆盖后还想沿用基类的实现，可以用 `super()` 调用它。

```python
class LoudCounter(Counter):
    def bump(self):
        value = super().bump()
        print("现在是", value)
        return value
```

在这个例子里，`super().bump()` 会调用 `Counter` 的 `bump`，并自动传入 `self`。派生类要扩展初始化时，可以先调用 `super().__init__(...)`，再设置自己的属性。`obj` 属于 `cls` 或其派生类时，`isinstance(obj, cls)` 返回 `True`。

继承适合表达「是一种」的关系，比如 `LoudCounter` 是一种 `Counter`。如果只是想用另一个对象提供的功能，通常把它存成属性就够了。这种做法叫组合。
