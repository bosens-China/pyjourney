## 类型标注

变量名或参数名后面的冒号引出类型标注。函数的返回值类型写在 `->` 后面。

```python
def average(scores: list[float]) -> float:
    return sum(scores) / len(scores)

counts: dict[str, int] = {}
nickname: str | None = None
```

标注容器时，先写内置类名，再用方括号说明其中的类型。`list[int]` 表示整数列表，`dict[str, int]` 表示键是字符串、值是整数的字典。`tuple[int, str]` 表示恰好有两项的元组，第一项是整数，第二项是字符串。

`X | Y` 表示两种类型都可以。例如 `str | None` 表示值可以是字符串，也可以是 `None`。

类型标注方便读者和工具理解代码。静态类型检查器读源码，可以在运行前指出类型不匹配的调用。Python 本身在运行时不检查标注。通常可以为公开的函数和类加上标注，把局部变量的类型留给检查器推断。

## 类型别名

同一个复杂的类型在多处用到时，可以用 `type` 语句给它起个名字。

```python
type Point = tuple[float, float]
type Polygon = list[Point]

def perimeter(shape: Polygon) -> float: ...
```

## 泛型

`first` 返回非空列表的第一项。传入 `list[int]` 就得到 `int`，传入 `list[str]` 就得到 `str`。类型参数把这种联系写明。声明时，把类型参数放进名字后面的方括号。

```python
def first[T](items: list[T]) -> T:  # [!code highlight]
    return items[0]

class Box[T]:
    def __init__(self, item: T) -> None:
        self.item = item

    def get(self) -> T:
        return self.item

type Pair[T] = tuple[T, T]
```

类型参数只在声明它的函数、类或类型别名里可见。`first`、`Box` 和 `Pair` 各自声明了自己的 `T`。

类型检查器根据每个调用处的实参推断 `T`。运行时，`first` 依然直接取出列表的第一项。

| 调用 | 静态推断 | 运行值 |
| --- | --- | --- |
| `n = first([8, 1])` | `T` 和 `n` 的类型都是 `int` | `n` 得到 `8` |
| `s = first(["a", "b"])` | `T` 和 `s` 的类型都是 `str` | `s` 得到 `"a"` |

## 限制类型参数的范围（选读）

用 `T: int` 把 `int` 设为上界，类型检查器可以推断出更具体的子类。用 `T: (str, bytes)` 列出候选类型，检查器会把 `T` 确定为其中一个。
