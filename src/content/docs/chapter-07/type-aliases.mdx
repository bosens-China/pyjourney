## 类型标注

类型标注写在名字后面的冒号之后，返回值的标注写在 `->` 之后：

```python
def average(scores: list[float]) -> float:
    return sum(scores) / len(scores)

counts: dict[str, int] = {}
nickname: str | None = None
```

容器类型直接写内置类名，方括号里写元素类型：`list[int]`、`dict[str, int]`、`tuple[int, str]`、`set[str]`。`X | Y` 表示两者之一，`str | None` 表示「字符串，或者没有值」。

Python 运行时不检查标注。它们是写给读者、编辑器和静态类型检查器的：检查器读源码，在程序运行之前指出类型对不上的调用。公开的函数和类写上标注，局部变量通常让检查器自己推断。

## 类型别名

类型写得很长、又多处重复时，用 `type` 语句给它起个名字：

```python
type Point = tuple[float, float]
type Polygon = list[Point]

def perimeter(shape: Polygon) -> float: ...
```

## 泛型

有的函数对任何类型都成立，但参数和返回值的类型之间有联系：`first` 返回列表的第一项，传入 `list[int]` 就得到 `int`，传入 `list[str]` 就得到 `str`。把这种联系写成类型参数，放在名字后面的方括号里：

```python
def first[T](items: list[T]) -> T:  # [!code highlight]
    return items[0]

class Box[T]:
    def __init__(self, item: T) -> None:
        self.item = item

    def get(self) -> T:
        return self.item

type Pair[T] = tuple[T, T]
```

类型参数只在这个函数、类或别名里可见，写完 `first` 之后，模块里并没有名字 `T`。`T: int` 限定它必须是 `int` 或其子类，`T: (str, bytes)` 限定它只能是列出的类型之一。运行时，泛型函数和泛型类的用法与普通函数、普通类相同。
