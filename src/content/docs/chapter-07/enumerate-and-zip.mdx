循环通常逐项取得一个序列中的元素。需要同时查看编号或另一组数据时，可以让循环每轮接收一对值。`enumerate()` 和 `zip()` 都可以生成这样的数据对。

## 用 enumerate 取得编号

`enumerate()` 每次提供一个编号和对应的元素。默认编号从 `0` 开始。用于展示序号时，可以传入 `start=1`，让第一项显示为 `1`。

```python
labels = ["alpha", "beta"]

for number, label in enumerate(labels, start=1):
    print(f"{number}. {label}")
```

输出为 `1. alpha` 和 `2. beta`，各占一行。这里调整的是编号起点，列表中的元素顺序保持原样。

## 用 zip 按位置配对

`zip()` 按位置从每个输入取一项，把这些项组合成一个元组。下面的第一轮取到 `("x", 2)`，第二轮取到 `("y", 5)`。循环会把每个元组解包到两个名字。

```python
names = ["x", "y"]
values = [2, 5]

for name, value in zip(names, values, strict=True):
    print(f"{name}={value}")
```

输出为 `x=2` 和 `y=5`。普通 `zip()` 在最短的一组用完时结束。如果数据理应逐项对应，使用 `strict=True`。当遍历到长度不一致的位置时，Python 会报告 `ValueError`。
