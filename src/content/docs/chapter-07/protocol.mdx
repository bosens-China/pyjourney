一个展示函数可以同时接收 Markdown 和纯文本文档。只要这两种对象都能用 `render()` 返回字符串，展示函数就可以按同一种方式调用它们。

要把这个要求写成类型标注，可以用 `typing.Protocol` 定义协议。下面的 `Renderable` 要求对象有一个返回字符串的 `render()` 方法。

```python run
from typing import Protocol

class Renderable(Protocol):
    def render(self) -> str:
        ...

class MarkdownDoc:
    def render(self) -> str:
        return "# Title"

class PlainText:
    def render(self) -> str:
        return "Title"

def display(doc: Renderable) -> str:
    return doc.render()

print(display(MarkdownDoc()))
print(display(PlainText()))
```

类型检查器会对照协议要求，判断类提供的方法是否符合要求。这种按对象具备的属性判断类型的方式叫**结构子类型**。以普通类名作标注时，检查器按类及其继承关系判断，这种方式叫**名义子类型**。

运行时，`display` 照常调用 `doc.render()`。协议也适用于标准库或第三方库中的类，只要它们提供所需的方法。

## 运行时检查（选读）

要用 `isinstance` 检查对象是否符合某个协议，可以给协议加上 `@runtime_checkable`。这种检查只确认属性是否存在，忽略类型签名。

```python run
from typing import Protocol, runtime_checkable

@runtime_checkable
class Closable(Protocol):
    def close(self) -> None:
        ...

class Door:
    def close(self) -> None:
        return None

door = Door()
print(isinstance(door, Closable))  # True
```

| 检查方式 | 对 `Closable` 检查什么 |
| --- | --- |
| 静态类型检查 | 比对 `close` 的签名，确认无需传参且返回 `None` |
| `isinstance(door, Closable)` | 确认实例有 `close`，忽略参数和返回值 |
