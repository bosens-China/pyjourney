名义子类型按继承关系判断。比如参数的类型标注是 `B`，就可以传入 `B` 或其子类的实例。结构子类型按对象具备的属性判断，只要这些属性符合协议，实现类就可以通过类型检查。

要定义协议，可以继承 `typing.Protocol`。下面的 `Renderable` 要求对象有一个返回字符串的 `render()` 方法。

```python
from typing import Protocol

class Renderable(Protocol):
    def render(self) -> str:
        ...

class MarkdownDoc:
    def render(self) -> str:
        return "# Title"

def display(doc: Renderable) -> str:
    return doc.render()
```

运行时，`display` 照常调用 `doc.render()`。`Protocol` 提供的约束由类型检查器判断。

协议也可以带类型参数，写法和泛型类一样，例如 `class Source[T](Protocol)`。

协议也适用于你无法修改的类。只要第三方库或标准库提供的对象符合协议，就可以直接传入。

## 运行时检查是另一条规则

要用 `isinstance` 检查对象是否符合某个协议，可以给协议加上 `@runtime_checkable`。这种检查只确认属性是否存在，忽略类型签名。

```python
from typing import Protocol, runtime_checkable

@runtime_checkable
class Closable(Protocol):
    def close(self) -> None:
        ...

class Door:
    def close(self) -> None:
        return None

door = Door()
print(isinstance(door, Closable))  # True
```

| 检查方式 | 对 `Closable` 检查什么 |
| --- | --- |
| 静态类型检查 | 比对 `close` 的签名，确认无需传参且返回 `None` |
| `isinstance(door, Closable)` | 确认实例有 `close`，忽略参数和返回值 |
