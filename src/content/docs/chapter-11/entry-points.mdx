有的模块同时承担两件事。你可以直接运行它来完成一次任务，也可以在其他文件里复用其中的函数。可以把直接运行时要做的事集中放进 `main()`，在文件末尾根据 `__name__` 决定是否调用它。

## 直接运行时执行 main

在本地练习目录创建 `text_summary.py`。

```python
def word_count(text):
    return len(text.split())


def main():
    count = word_count("red blue green")
    print(f"词数为 {count}")


if __name__ == "__main__":
    main()
```

运行 `python text_summary.py`，会输出“词数为 3”。直接运行该文件时，Python 将其中的 `__name__` 设为 `"__main__"`。条件成立，程序调用 `main()`。

`main` 是常用的函数名。文件末尾的 `main()` 调用负责执行它。

## 导入时保留函数定义

在同一目录下创建 `inspect_text.py`。

```python
from text_summary import word_count

print(word_count("apple pear"))
```

运行 `python inspect_text.py`，会输出 `2`。这次，`text_summary.py` 通过导入执行，其中的 `__name__` 是 `"text_summary"`。Python 创建模块中的函数，跳过末尾的 `main()` 调用。调用方随后使用已经导入的 `word_count()`。
