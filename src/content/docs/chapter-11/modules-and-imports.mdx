写好一个函数以后，其他程序也可能需要它。可以把这个函数放进单独的 `.py` 文件，再通过 `import` 使用。这样的文件是一种模块。导入者用模块名找到其中的函数。

## 导入标准库模块

```python
import math

boxes = math.ceil(25 / 12)
print(boxes)  # 3
```

`math` 是 Python 标准库的一部分。`math.ceil()` 返回大于或等于给定数值的最小整数。每箱装 12 件，25 件会占用 2 个满箱和 1 个未装满的箱子，因此结果是 3。

`import math` 会在当前代码中提供模块名 `math`。调用时写出 `math.ceil()`，读代码的人可以直接看到函数来自哪里。

如果只需要使用一个名称，也可以写成 `from math import ceil`。这种形式把 `ceil` 绑定到当前代码中，调用时写 `ceil()` 即可。

## 导入自己编写的模块

在本地练习目录创建两个文件。先把清理标签的规则放进 `text_tools.py`。

```python
def clean_tag(text):
    return text.strip().lower()
```

在同一目录下创建 `show_tags.py`，从中导入 `text_tools`。

```python
import text_tools

tag = text_tools.clean_tag("  Python ")
print(tag)
```

在练习目录运行 `python show_tags.py`，会输出 `python`。`import text_tools` 使用文件名中去掉 `.py` 后缀的部分。`text_tools.clean_tag()` 取得模块里定义的函数。

后续如果另一个文件也要清理标签，可以导入同一个函数。修改清理规则时，只需在 `text_tools.py` 中维护它。
