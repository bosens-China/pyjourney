如果只需要按行处理文件，可以用 `Path.open()` 打开文件，再用 `for` 遍历文件对象。把这段操作放进 `with`，离开缩进块时，文件会自动关闭。即使处理某一行时发生异常，关闭操作也会执行。

## 打开、读取和关闭

```python
from pathlib import Path

path = Path("chapter10-checklist.txt")
path.write_text("开窗\n备水\n", encoding="utf-8")

with path.open("r", encoding="utf-8") as source:
    for line in source:
        print(line.rstrip("\n"))

print(source.closed)
```

`"r"` 代表以读取模式打开文件。`as source` 给打开的文件对象起名。循环每次拿到一行字符串，行尾有换行符时，`rstrip("\n")` 会去掉它。这样 `print()` 可以为每项结果加上一个换行。

`print(source.closed)` 位于 `with` 之外，会显示 `True`。此时文件已经关闭，文件对象仍然可以用来查看 `closed` 属性。

## 需要追加时改变打开模式

要把一行内容加到末尾，可以用追加模式 `"a"`。文件已经存在时，写入位置在末尾。目标文件还不存在时，追加模式会创建文件。

```python
from pathlib import Path

path = Path("chapter10-checklist.txt")
with path.open("a", encoding="utf-8") as target:
    target.write("关灯\n")
```

`write()` 按传入的字符串写入内容。想让下一项另起一行，就在写入的字符串末尾加上 `\n`。
